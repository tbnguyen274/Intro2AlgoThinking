# Bài 21: Tìm Cây Khung Nhỏ Nhất Thứ K

## Đề Bài

Ở quốc gia SSS, có **N** thành phố và **M** tuyến đường tàu hỏa kết nối chúng. Độ dài của mỗi tuyến đường là khác nhau, và đảm bảo rằng giữa bất kỳ cặp thành phố nào cũng tồn tại ít nhất một tuyến đường (trực tiếp hoặc gián tiếp) nối chúng.

Chính phủ quyết định nâng cấp các tuyến đường thành hệ thống tàu siêu tốc mới, đảm bảo rằng giữa mỗi cặp thành phố luôn tồn tại ít nhất một tuyến đường sử dụng công nghệ mới. Mục tiêu là tìm kế hoạch tối ưu sao cho tổng độ dài các tuyến đường cần nâng cấp là ít nhất.

Tuy nhiên, để đối phó với tình huống có thể xảy ra sự cố, chính phủ cũng muốn xác định **K** kế hoạch khác nhau. Hai kế hoạch được coi là khác nhau nếu ít nhất một tuyến đường được nâng cấp trong một kế hoạch nhưng không được nâng cấp trong kế hoạch khác.

**Dữ liệu vào:**
- Dòng đầu chứa 3 số $N, M, K$
- $M$ dòng tiếp theo, mỗi dòng chứa 3 số $u, v, c$ (cạnh nối từ $u$ đến $v$ có độ dài $c$)

**Kết quả:**
- In ra một số nguyên là tổng độ dài của các tuyến đường cần nâng cấp của kế hoạch dự phòng thứ $K$

**Ví dụ:**
```
INPUT:
5 6 2
1 2 2
1 3 4
2 4 3
2 5 1
3 5 5
4 5 6

OUTPUT:
11

GIẢI THÍCH:
Các tuyến đường cần nâng cấp trong kế hoạch thứ K gồm:
1 2
2 5
2 4
3 5
```

## Phân Tích Bài Toán

### Hiểu Đề Bài

Đây là bài toán **K-th Minimum Spanning Tree** (MST thứ K).

**Định nghĩa:**
- **Spanning Tree (Cây khung):** Tập con các cạnh kết nối tất cả đỉnh mà không tạo chu trình
  - Với $N$ đỉnh, cần đúng $N-1$ cạnh
- **Minimum Spanning Tree (MST):** Cây khung có tổng trọng số nhỏ nhất

**Bài toán:**
- Tìm $K$ cây khung có tổng trọng số nhỏ nhất
- In ra tổng trọng số của cây khung thứ $K$

### Visualization

**Example:** 5 đỉnh, 6 cạnh

```
    1 ----2---- 2
    |           |
    4           1
    |           |
    3 ----5---- 5
     \         /
      5       6
       \     /
        \   /
          4
```

Các cạnh:
- (2,5): 1
- (1,2): 2  
- (2,4): 3
- (1,3): 4
- (3,5): 5
- (4,5): 6

**MST 1:** (2,5), (1,2), (2,4), (1,3) → Total: 1+2+3+4 = **10**

**MST 2:** (2,5), (1,2), (2,4), (3,5) → Total: 1+2+3+5 = **11**

Output: **11** (K=2)

## Kiến Thức Cơ Bản

### 1. Disjoint Set Union (DSU)

**Mục đích:** Quản lý các tập hợp rời rạc, hỗ trợ:
- `find(x)`: Tìm đại diện (root) của tập chứa $x$
- `unite(x, y)`: Hợp nhất 2 tập chứa $x$ và $y$

**Tóm tắt:**
- Lớp này cài đặt **Disjoint Set Union (Union–Find)** để quản lý các tập rời nhau.
- `find` dùng **path compression** để tìm nhanh đại diện, còn `unite` dùng **union by rank** để gộp hai tập hiệu quả và tránh cây bị cao.


**Implementation:**

```cpp
class DSU {
private:
    vector<int> parent, rank;
    
public:
    DSU(int n) {
        parent.resize(n + 1);
        rank.resize(n + 1, 0);
        for (int i = 0; i <= n; i++) {
            parent[i] = i; // Mỗi đỉnh là root của chính nó
        }
    }
    
    // Path compression: Gán trực tiếp parent = root
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    // Union by rank: Gắn cây nhỏ vào cây lớn
    bool unite(int x, int y) {
        int px = find(x);
        int py = find(y);
        
        if (px == py) return false; // Cùng tập
        
        if (rank[px] < rank[py]) {
            parent[px] = py;
        } else if (rank[px] > rank[py]) {
            parent[py] = px;
        } else {
            parent[py] = px;
            rank[px]++;
        }
        
        return true;
    }
};
```

**Time Complexity:** $O(\alpha(n))$ ≈ $O(1)$ amortized

$\alpha(n)$ là hàm Ackermann nghịch đảo, cực kỳ nhỏ (< 5 với mọi $n$ thực tế)

### 2. Kruskal's Algorithm

**Thuật toán tìm MST:**

1. **Sắp xếp** các cạnh theo trọng số tăng dần
2. **Duyệt** qua các cạnh:
   - Nếu 2 đỉnh chưa cùng tập (DSU): Thêm cạnh vào MST
   - Ngược lại: Bỏ qua (tạo chu trình)
3. **Dừng** khi có $N-1$ cạnh

**Cài đặt:**

```cpp
long long kruskal(int n, vector<Edge>& edges) {
    sort(edges.begin(), edges.end()); // Sort by cost
    
    DSU dsu(n);
    long long total_cost = 0;
    int edges_used = 0;
    
    for (Edge& e : edges) {
        if (dsu.unite(e.u, e.v)) {
            total_cost += e.cost;
            edges_used++;
            
            if (edges_used == n - 1) break;
        }
    }
    
    return total_cost;
}
```

**Time Complexity:** $O(M \log M + M \alpha(N)) \approx O(M \log M)$

## Approach 1: Brute Force - Liệt Kê Tất Cả

### Ý Tưởng

1. **Sinh tất cả tập con** có $N-1$ cạnh
2. **Kiểm tra** xem có tạo thành cây khung không (dùng DSU)
3. **Tính tổng** trọng số
4. **Sắp xếp** và lấy cây khung thứ $K$

### Giải thuật

- Duyệt **mọi tập con gồm đúng (n-1) cạnh** trong (m) cạnh để tìm tất cả các **cây khung hợp lệ**.
- Với mỗi tập cạnh được chọn, dùng **DSU** để kiểm tra có tạo chu trình không và nếu hợp lệ thì tính tổng chi phí, lưu vào danh sách; cuối cùng **sắp xếp các chi phí** và trả về **giá trị nhỏ thứ k** (tương ứng cây khung nhỏ thứ k).


### Code Implementation

```cpp
long long bruteForceSolution(int n, int m, int k, vector<Edge>& edges) {
    vector<long long> all_costs;
    
    // Duyệt tất cả tập con có (n-1) cạnh
    function<void(int, vector<int>&)> generate = 
        [&](int idx, vector<int>& selected) {
        
        if (selected.size() == n - 1) {
            // Kiểm tra xem có tạo thành cây khung không
            DSU dsu(n);
            long long cost = 0;
            
            for (int i : selected) {
                if (!dsu.unite(edges[i].u, edges[i].v)) {
                    return; // Tạo chu trình
                }
                cost += edges[i].cost;
            }
            
            all_costs.push_back(cost);
            return;
        }
        
        if (idx >= m) return;
        
        // Chọn cạnh này
        selected.push_back(idx);
        generate(idx + 1, selected);
        selected.pop_back();
        
        // Không chọn cạnh này
        generate(idx + 1, selected);
    };
    
    vector<int> selected;
    generate(0, selected);
    
    sort(all_costs.begin(), all_costs.end());
    
    return all_costs[k - 1];
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(\binom{M}{N-1} \times N)$

- $\binom{M}{N-1}$ tập con
- Mỗi tập: kiểm tra $O(N)$ với DSU

**Đánh Giá:**

Với $M = 100, N = 50$:
$$\binom{100}{49} \approx 10^{28}$$

**Không khả thi!**

## Approach 2: Backtracking với Pruning

### Ý Tưởng Tối Ưu

**Key Insights:**

1. **Sắp xếp cạnh trước:** Theo thứ tự Kruskal → sinh cây khung nhỏ trước. Giúp ưu tiên duyệt các nhánh có chi phí nhỏ trước, từ đó sớm thu được nhiều cây khung chi phí thấp.
2. **Backtracking kết hợp DSU:** Ở mỗi bước, thử *chọn / không chọn* cạnh hiện tại, dùng DSU để đảm bảo không tạo chu trình khi xây dựng cây khung.
3. **Pruning theo số nghiệm:** Khi đã thu thập đủ số lượng cây khung tiềm năng, dừng các nhánh sâu hơn để giảm không gian tìm kiếm.


### Algorithm

```
1. Sort edges by cost
2. Use backtracking to generate spanning trees:
   - At each step, try including/excluding current edge
   - Use DSU to check validity
   - Stop when have K spanning trees
3. Return K-th smallest
```

### Visualization

**Backtracking Tree:**

```
                    Start (0 edges)
                    /           \
            Include e1      Exclude e1
             /     \             /    \
        +e2    -e2          +e2    -e2
        ...    ...          ...    ...
```

Duyệt theo DFS, mỗi nút là một trạng thái (tập cạnh đã chọn)

### Code Implementation

```cpp
long long solve(int n, int m, int k, vector<Edge>& edges) {
    sort(edges.begin(), edges.end());
    
    multiset<long long> all_costs;
    
    function<void(int, DSU&, long long, int)> backtrack = 
        [&](int idx, DSU& dsu, long long cost, int edges_used) {
        
        // Base case: Get the Spanning Tree
        if (edges_used == n - 1) {
            all_costs.insert(cost);
            return;
        }
        
        // Pruning
        if (idx >= m) return;
        if (all_costs.size() > k * 100) return; // Enough
        
        // Branch 1: Include this edge
        DSU dsu_copy = dsu;
        if (dsu_copy.unite(edges[idx].u, edges[idx].v)) {
            backtrack(idx + 1, dsu_copy, 
                     cost + edges[idx].cost, edges_used + 1);
        }
        
        // Branch 2: Exclude this edge
        backtrack(idx + 1, dsu, cost, edges_used);
    };
    
    DSU initial_dsu(n);
    backtrack(0, initial_dsu, 0, 0);
    
    auto it = all_costs.begin();
    advance(it, k - 1);
    return *it;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(2^M)$ worst case

Tuy nhiên, với pruning:
- Average case: $O(K \times M \times N)$
- Thực tế chạy nhanh hơn nhiều

**Space Complexity:** $O(M + N + K)$

## Solution Cuối Cùng

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <set>
#include <functional>

using namespace std;

struct Edge {
    int u, v, cost;
    bool operator<(const Edge& other) const {
        return cost < other.cost;
    }
};

class DSU {
private:
    vector<int> parent, rank;
public:
    DSU(int n) {
        parent.resize(n + 1);
        rank.resize(n + 1, 0);
        for (int i = 0; i <= n; i++) parent[i] = i;
    }
    
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);
        return parent[x];
    }
    
    bool unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false;
        if (rank[px] < rank[py]) parent[px] = py;
        else if (rank[px] > rank[py]) parent[py] = px;
        else { parent[py] = px; rank[px]++; }
        return true;
    }
};

long long solve(int n, int m, int k, vector<Edge>& edges) {
    sort(edges.begin(), edges.end());
    multiset<long long> all_costs;
    
    function<void(int, DSU&, long long, int)> backtrack = 
        [&](int idx, DSU& dsu, long long cost, int edges_used) {
        if (edges_used == n - 1) {
            all_costs.insert(cost);
            return;
        }
        if (idx >= m || all_costs.size() > k * 100) return;
        
        DSU dsu_copy = dsu;
        if (dsu_copy.unite(edges[idx].u, edges[idx].v)) {
            backtrack(idx + 1, dsu_copy, cost + edges[idx].cost, edges_used + 1);
        }
        backtrack(idx + 1, dsu, cost, edges_used);
    };
    
    DSU initial_dsu(n);
    backtrack(0, initial_dsu, 0, 0);
    
    auto it = all_costs.begin();
    advance(it, k - 1);
    return *it;
}

int main() {
    int n, m, k;
    cin >> n >> m >> k;
    
    vector<Edge> edges(m);
    for (int i = 0; i < m; i++) {
        cin >> edges[i].u >> edges[i].v >> edges[i].cost;
    }
    
    cout << solve(n, m, k, edges) << endl;
    return 0;
}
```

## Tổng Kết Phỏng Vấn

### Quy Trình Giải Quyết

1. **Nhận dạng bài toán:** K-th Minimum Spanning Tree
2. **Kiến thức cơ bản:** DSU, Kruskal's algorithm
3. **Brute force:** Liệt kê tất cả spanning trees
4. **Tối ưu với backtracking:** Sinh có hệ thống + pruning
5. **Phân tích trade-offs:** Time vs Space, completeness vs efficiency

### Key Points

- **Time:** $O(2^M)$ worst case, nhưng pruning giúp chạy nhanh
- **Space:** $O(M + N + K)$
- **DSU:** Cấu trúc quan trọng, $O(\alpha(n)) \approx O(1)$
- **Kruskal:** Nền tảng để tìm MST, $O(M \log M)$

### Câu Hỏi Mở Rộng Có Thể Gặp

**Q: Nếu cần tìm tất cả MST (không chỉ K)?**
- A: Dùng thuật toán đặc biệt như Gabow-Myers, nhưng phức tạp cao

**Q: Prim's algorithm có dùng được không?**
- A: Có, nhưng Kruskal phù hợp hơn với bài này vì dễ backtrack

**Q: Nếu K rất lớn (10^6)?**
- A: Cần thuật toán khác, có thể approximate hoặc sampling

**Q: Làm sao đảm bảo tìm đúng K MST nhỏ nhất?**
- A: Backtracking theo thứ tự cạnh đã sort đảm bảo sinh MST nhỏ trước

**Q: Bài toán liên quan?**
- A: MST variants, Steiner Tree, k-MST, Degree-constrained MST
