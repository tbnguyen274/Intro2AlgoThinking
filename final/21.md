# Bài 21: Tìm Cây Khung Nhỏ Nhất Thứ K

## Đề Bài

Ở quốc gia SSS, có **N** thành phố và **M** tuyến đường tàu hỏa kết nối chúng. Độ dài của mỗi tuyến đường là khác nhau, và đảm bảo rằng giữa bất kỳ cặp thành phố nào cũng tồn tại ít nhất một tuyến đường (trực tiếp hoặc gián tiếp) nối chúng.

Chính phủ quyết định nâng cấp các tuyến đường thành hệ thống tàu siêu tốc mới, đảm bảo rằng giữa mỗi cặp thành phố luôn tồn tại ít nhất một tuyến đường sử dụng công nghệ mới. Mục tiêu là tìm kế hoạch tối ưu sao cho tổng độ dài các tuyến đường cần nâng cấp là ít nhất.

Tuy nhiên, để đối phó với tình huống có thể xảy ra sự cố, chính phủ cũng muốn xác định **K** kế hoạch khác nhau. Hai kế hoạch được coi là khác nhau nếu ít nhất một tuyến đường được nâng cấp trong một kế hoạch nhưng không được nâng cấp trong kế hoạch khác.

**Dữ liệu vào:**
- Dòng đầu chứa 3 số $N, M, K$
- $M$ dòng tiếp theo, mỗi dòng chứa 3 số $u, v, c$ (cạnh nối từ $u$ đến $v$ có độ dài $c$)

**Kết quả:**
- In ra một số nguyên là tổng độ dài của các tuyến đường cần nâng cấp của kế hoạch dự phòng thứ $K$

**Ví dụ:**

INPUT:
```
5 6 2
1 2 2
1 3 4
2 4 3
2 5 1
3 5 5
4 5 6
```
OUTPUT:
```
11
```

GIẢI THÍCH:
```
Các tuyến đường cần nâng cấp trong kế hoạch thứ K gồm:
1 2
2 5
2 4
3 5
```

## Phân Tích Bài Toán

### Hiểu Đề Bài

Đây là bài toán **K-th Minimum Spanning Tree** (MST thứ K).

**Định nghĩa:**
- **Spanning Tree (Cây khung):** Tập con các cạnh kết nối tất cả đỉnh mà không tạo chu trình
  - Với $N$ đỉnh, cần đúng $N-1$ cạnh
- **Minimum Spanning Tree (MST):** Cây khung có tổng trọng số nhỏ nhất

**Bài toán:**
- Tìm $K$ cây khung có tổng trọng số nhỏ nhất
- In ra tổng trọng số của cây khung thứ $K$

### Visualization

**Example:** 5 đỉnh, 6 cạnh

```
    1 ----2---- 2
    |           |
    4           1
    |           |
    3 ----5---- 5
     \         /
      5       6
       \     /
        \   /
          4
```

Các cạnh:
- (2,5): 1
- (1,2): 2  
- (2,4): 3
- (1,3): 4
- (3,5): 5
- (4,5): 6

**MST 1:** (2,5), (1,2), (2,4), (1,3) → Total: 1+2+3+4 = **10**

**MST 2:** (2,5), (1,2), (2,4), (3,5) → Total: 1+2+3+5 = **11**

Output: **11** (K=2)

## Kiến Thức Cơ Bản

### 1. Disjoint Set Union (DSU)

**Mục đích:** Quản lý các tập hợp rời rạc, hỗ trợ:
- `find(x)`: Tìm đại diện (root) của tập chứa $x$
- `unite(x, y)`: Hợp nhất 2 tập chứa $x$ và $y$

**Tóm tắt:**
- Lớp này cài đặt **Disjoint Set Union (Union–Find)** để quản lý các tập rời nhau.
- `find` dùng **path compression** để tìm nhanh đại diện, còn `unite` dùng **union by rank** để gộp hai tập hiệu quả và tránh cây bị cao.


**Implementation:**

```cpp
class DSU {
private:
    vector<int> parent, rank;  // parent[i]: cha của đỉnh i, rank[i]: độ cao ước lượng
    
public:
    // Khởi tạo DSU với n đỉnh, mỗi đỉnh là một tập riêng biệt
    DSU(int n) {
        parent.resize(n + 1);
        rank.resize(n + 1, 0);  // Rank ban đầu = 0
        for (int i = 0; i <= n; i++) {
            parent[i] = i;  // Mỗi đỉnh là root của chính nó
        }
    }
    
    // Path compression: Gán trực tiếp parent = root để tối ưu tìm kiếm sau này
    // Time: O(α(n)) ≈ O(1) amortized
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);  // Nén đường đi, gán thẳng về root
        }
        return parent[x];
    }
    
    // Union by rank: Gắn cây nhỏ vào cây lớn để giữ cây cân bằng
    // Return: true nếu gộp thành công, false nếu đã cùng tập (tạo chu trình)
    bool unite(int x, int y) {
        int px = find(x);  // Tìm root của x
        int py = find(y);  // Tìm root của y
        
        if (px == py) return false;  // Cùng tập → tạo chu trình
        
        // Gắn cây rank nhỏ vào cây rank lớn
        if (rank[px] < rank[py]) {
            parent[px] = py;  // px trở thành con của py
        } else if (rank[px] > rank[py]) {
            parent[py] = px;  // py trở thành con của px
        } else {
            parent[py] = px;  // Rank bằng nhau, chọn px làm root
            rank[px]++;       // Tăng rank của px
        }
        
        return true;  // Gộp thành công
    }
};
```

**Time Complexity:** $O(\alpha(n))$ ≈ $O(1)$ amortized

$\alpha(n)$ là hàm Ackermann nghịch đảo, cực kỳ nhỏ (< 5 với mọi $n$ thực tế)

### 2. Kruskal's Algorithm

**Thuật toán tìm MST:**

1. **Sắp xếp** các cạnh theo trọng số tăng dần
2. **Duyệt** qua các cạnh:
   - Nếu 2 đỉnh chưa cùng tập (DSU): Thêm cạnh vào MST
   - Ngược lại: Bỏ qua (tạo chu trình)
3. **Dừng** khi có $N-1$ cạnh

**Cài đặt:**

```cpp
// Kruskal's Algorithm: Tìm cây khung nhỏ nhất (MST)
// Time: O(M log M) cho sort + O(M × α(N)) cho DSU ≈ O(M log M)
long long kruskal(int n, vector<Edge>& edges) {
    // Bước 1: Sắp xếp các cạnh theo trọng số tăng dần
    sort(edges.begin(), edges.end());  // O(M log M)
    
    DSU dsu(n);              // Khởi tạo DSU với n đỉnh
    long long total_cost = 0;  // Tổng trọng số MST
    int edges_used = 0;        // Số cạnh đã thêm vào MST
    
    // Bước 2: Duyệt các cạnh theo thứ tự trọng số
    for (Edge& e : edges) {
        // Thử thêm cạnh: chỉ thêm nếu không tạo chu trình
        if (dsu.unite(e.u, e.v)) {  // O(α(N)) ≈ O(1)
            total_cost += e.cost;    // Cộng trọng số
            edges_used++;            // Đếm số cạnh
            
            // Đủ N-1 cạnh → Đã có cây khung hoàn chỉnh
            if (edges_used == n - 1) break;
        }
        // Nếu unite() = false → 2 đỉnh đã cùng tập → bỏ qua (tránh chu trình)
    }
    
    return total_cost;
}
```

**Time Complexity:** $O(M \log M + M \alpha(N)) \approx O(M \log M)$

## Approach 1: Brute Force - Liệt Kê Tất Cả

### Ý Tưởng

**Bài toán: K-th Minimum Spanning Tree**

Tìm cây khung có tổng trọng số nhỏ thứ K trong tất cả các cây khung có thể.

**Spanning Tree là gì?**
- Tập con các cạnh kết nối **tất cả đỉnh**
- **Không tạo chu trình** (graph dạng cây)
- Với $N$ đỉnh, cần đúng $N-1$ cạnh

**Cách tiếp cận Brute Force:**

**Bước 1: Sinh tất cả tập con $(N-1)$ cạnh**

Với $M$ cạnh, có $\binom{M}{N-1}$ cách chọn:
$$\binom{M}{N-1} = \frac{M!}{(N-1)! \times (M-N+1)!}$$

Ví dụ: $M=6, N=5$ → $\binom{6}{4} = 15$ tập con

**Thuật toán sinh tập con:**
Dùng **backtracking/recursion**:
```
generate(idx, selected):
    if len(selected) == N-1:
        // Kiểm tra tập này
        return
    
    if idx >= M:
        return
    
    // Chọn cạnh idx
    selected.add(idx)
    generate(idx+1, selected)
    selected.remove(idx)
    
    // Không chọn cạnh idx
    generate(idx+1, selected)
```

**Bước 2: Kiểm tra tính hợp lệ (là Spanning Tree?)**

Với mỗi tập $(N-1)$ cạnh, kiểm tra:

**Điều kiện 1: Kết nối tất cả đỉnh**
Dùng **DSU (Disjoint Set Union)**:
- Ban đầu: Mỗi đỉnh là một tập riêng biệt
- Thêm từng cạnh: Gộp 2 tập lại
- Cuối cùng: Nếu tất cả đỉnh trong 1 tập → kết nối ✓

**Điều kiện 2: Không tạo chu trình**
Cũng dùng DSU:
- Nếu 2 đỉnh của cạnh **đã cùng tập** → thêm cạnh sẽ tạo chu trình → REJECT
- Nếu **khác tập** → gộp lại → OK

**DSU Operation:**
```
DSU dsu(N)
for edge in selected_edges:
    if !dsu.unite(edge.u, edge.v):
        return false  // Chu trình!
        
return true  // Hợp lệ
```

**Bước 3: Tính tổng trọng số**

Nếu tập cạnh hợp lệ:
```
cost = sum(edge.weight for edge in selected_edges)
all_costs.append(cost)
```

**Bước 4: Sắp xếp và lấy phần tử thứ K**
```
all_costs.sort()
return all_costs[K-1]  // 0-indexed
```

**Tại sao approach này chậm?**

**Độ phức tạp:** $O(\binom{M}{N-1} \times N \times \alpha(N))$

Với $M=100, N=50$:
$$\binom{100}{49} \approx 10^{28}$$

→ **Hoàn toàn KHÔNG KHẢ THI!**

Vấn đề:
- Sinh quá nhiều tập con
- Nhiều tập không hợp lệ (tạo chu trình)
- Không tận dụng cấu trúc của bài toán

### Giải thuật

- Duyệt **mọi tập con gồm đúng (n-1) cạnh** trong (m) cạnh để tìm tất cả các **cây khung hợp lệ**.
- Với mỗi tập cạnh được chọn, dùng **DSU** để kiểm tra có tạo chu trình không và nếu hợp lệ thì tính tổng chi phí, lưu vào danh sách; cuối cùng **sắp xếp các chi phí** và trả về **giá trị nhỏ thứ k** (tương ứng cây khung nhỏ thứ k).


### Code Implementation

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <functional>
using namespace std;

struct Edge {
    int u, v, cost;
    bool operator<(const Edge& other) const {
        return cost < other.cost;
    }
};

class DSU {
private:
    vector<int> parent, rank;
public:
    DSU(int n) {
        parent.resize(n + 1);
        rank.resize(n + 1, 0);
        for (int i = 0; i <= n; i++) {
            parent[i] = i;
        }
    }
    
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    bool unite(int x, int y) {
        int px = find(x);
        int py = find(y);
        
        if (px == py) return false;
        
        if (rank[px] < rank[py]) {
            parent[px] = py;
        } else if (rank[px] > rank[py]) {
            parent[py] = px;
        } else {
            parent[py] = px;
            rank[px]++;
        }
        return true;
    }
};

// Brute Force: Sinh tất cả tập con (N-1) cạnh và kiểm tra tính hợp lệ
// Time: O(C(M, N-1) × N × α(N)) - cực kỳ chậm với M, N lớn
long long bruteForceSolution(int n, int m, int k, vector<Edge>& edges) {
    vector<long long> all_costs;  // Lưu tổng trọng số của tất cả cây khung hợp lệ
    
    // Hàm đệ quy sinh tất cả tập con có (n-1) cạnh
    function<void(int, vector<int>&)> generate = 
        [&](int idx, vector<int>& selected) {
        
        // Base case: Đã chọn đủ N-1 cạnh
        if (selected.size() == n - 1) {
            // Kiểm tra xem có tạo thành cây khung hợp lệ không
            DSU dsu(n);
            long long cost = 0;
            
            // Thử thêm tất cả cạnh đã chọn
            for (int i : selected) {
                if (!dsu.unite(edges[i].u, edges[i].v)) {
                    return;  // Tạo chu trình → Không hợp lệ → Bỏ qua
                }
                cost += edges[i].cost;  // Cộng dồn trọng số
            }
            
            // Tập cạnh hợp lệ → Lưu tổng trọng số
            all_costs.push_back(cost);
            return;
        }
        
        // Hết cạnh để chọn
        if (idx >= m) return;
        
        // Nhánh 1: CHỌN cạnh idx
        selected.push_back(idx);
        generate(idx + 1, selected);
        selected.pop_back();  // Backtrack
        
        // Nhánh 2: KHÔNG CHỌN cạnh idx
        generate(idx + 1, selected);
    };
    
    vector<int> selected;  // Tập cạnh đang chọn
    generate(0, selected);  // Bắt đầu từ cạnh 0
    
    // Sắp xếp các tổng trọng số tăng dần
    sort(all_costs.begin(), all_costs.end());
    
    // Trả về cây khung nhỏ thứ K (0-indexed)
    return all_costs[k - 1];
}

int main() {
    int n, m, k;
    cin >> n >> m >> k;
    
    vector<Edge> edges(m);
    for (int i = 0; i < m; i++) {
        cin >> edges[i].u >> edges[i].v >> edges[i].cost;
    }
    
    long long result = bruteForceSolution(n, m, k, edges);
    cout << result << endl;
    
    return 0;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(\binom{M}{N-1} \times N)$

- $\binom{M}{N-1}$ tập con
- Mỗi tập: kiểm tra $O(N)$ với DSU

**Đánh Giá:**

Với $M = 100, N = 50$:
$$\binom{100}{49} \approx 10^{28}$$

**Không khả thi!**

## Approach 2: Backtracking với Pruning

### Ý Tưởng

**Cải tiến từ Brute Force:**

Thay vì sinh mù loạng tất cả, sinh **có hệ thống** và **cắt tỉa** các nhánh vô dụng.

**Key Insights:**

**1. Sắp xếp cạnh trước (Greedy Heuristic)**

Sắp xếp các cạnh theo trọng số tăng dần (giống Kruskal):
```
sort(edges by weight)
```

**Tại sao hiệu quả?**
- Cây khung nhỏ sẽ ưu tiên cạnh nhỏ
- Sinh các cây khung tốt trước
- Nhanh chóng tìm được K cây khung nhỏ nhất

**Ví dụ:**
```
Cạnh ban đầu: [(u,v,5), (a,b,2), (x,y,8), (p,q,1)]
Sau sort:       [(p,q,1), (a,b,2), (u,v,5), (x,y,8)]
→ Thử cạnh nhỏ trước!
```

**2. Backtracking với DSU**

Tại mỗi bước, quyết định: **Chọn** hoặc **Không chọn** cạnh hiện tại

**Thuật toán:**
```
backtrack(idx, dsu, cost, edges_used):
    // Base case: Đủ N-1 cạnh
    if edges_used == N-1:
        all_costs.add(cost)
        return
    
    // Pruning: Hết cạnh hoặc đủ kết quả
    if idx >= M or all_costs.size() > K*100:
        return
    
    // Branch 1: CHỌỌN cạnh này
    dsu_copy = copy(dsu)
    if dsu_copy.unite(edges[idx].u, edges[idx].v):
        // Không tạo chu trình → OK
        backtrack(idx+1, dsu_copy, 
                 cost + edges[idx].cost, 
                 edges_used + 1)
    
    // Branch 2: KHÔNG CHỌN cạnh này
    backtrack(idx+1, dsu, cost, edges_used)
```

**Cây quyết định:**
```
                  Start
                 /     \
          +e1 (OK)     -e1
           /    \       /   \
      +e2      -e2   +e2   -e2
      /  \     /  \   /  \   /  \
    ...
```

**3. Pruning Strategies (Cắt tỉa)**

**Pruning 1: Early stop khi đủ kết quả**
```
if all_costs.size() > K * 100:
    return  // Đã có đủ nhiều cây khung
```
- Không cần tìm tất cả, chỉ cần > K
- Nhân 100 để đảm bảo có đủ lựa chọn

**Pruning 2: Skip cạnh tạo chu trình**
```
if !dsu_copy.unite(u, v):
    // Tạo chu trình → bỏ qua nhánh này
    continue
```
- Không cần thử các cạnh tiếp theo nếu đã tạo chu trình

**Pruning 3: Impossible check**
```
if idx + (N-1-edges_used) > M:
    return  // Không đủ cạnh còn lại
```
- Nếu số cạnh còn lại < số cạnh cần → không thể tạo cây khung

**4. Lưu kết quả với multiset**
```
multiset<long long> all_costs;
```
- Tự động sắp xếp
- Cho phép trùng lặp (nhiều cây khung có thể cùng chi phí)
- Truy xuất phần tử thứ K: $O(K)$

**Tại sao hiệu quả hơn?**

**So sánh:**
| | Brute Force | Backtracking + Pruning |
|---|---|---|
| Sắp xếp trước | Không | Có (greedy) |
| Kiểm tra chu trình | Cuối | Trong quá trình |
| Cắt tỉa | Không | Nhiều loại |
| Số trạng thái | $2^M$ | $\ll 2^M$ |

**Độ phức tạp:**
- Worst case: Vẫn $O(2^M)$
- Average case: **$O(K \times M \times N)$** với pruning tốt
- Thực tế: Chạy nhanh hơn **đáng kể** nhờ:
  - Sắp xếp thông minh
  - Early stopping
  - Cắt tỉa nhiều nhánh vô dụng


### Algorithm

```
1. Sort edges by cost
2. Use backtracking to generate spanning trees:
   - At each step, try including/excluding current edge
   - Use DSU to check validity
   - Stop when have K spanning trees
3. Return K-th smallest
```

### Visualization

**Backtracking Tree:**

```
                    Start (0 edges)
                    /           \
            Include e1      Exclude e1
             /     \             /    \
        +e2    -e2          +e2    -e2
        ...    ...          ...    ...
```

Duyệt theo DFS, mỗi nút là một trạng thái (tập cạnh đã chọn)

### Code Implementation

```cpp

#include <vector>
#include <algorithm>
#include <set>
#include <functional>
using namespace std;

struct Edge {
    int u, v, cost;
    bool operator<(const Edge& other) const {
        return cost < other.cost;
    }
};

class DSU {
private:
    vector<int> parent, rank;
public:
    DSU(int n) {
        parent.resize(n + 1);
        rank.resize(n + 1, 0);
        for (int i = 0; i <= n; i++) {
            parent[i] = i;
        }
    }
    
    int find(int x) {
        if (parent[x] != x) {
            parent[x] = find(parent[x]);
        }
        return parent[x];
    }
    
    bool unite(int x, int y) {
        int px = find(x);
        int py = find(y);
        
        if (px == py) return false;
        
        if (rank[px] < rank[py]) {
            parent[px] = py;
        } else if (rank[px] > rank[py]) {
            parent[py] = px;
        } else {
            parent[py] = px;
            rank[px]++;
        }
        return true;
    }
};

// Backtracking với Pruning: Sinh cây khung có hệ thống, cắt tỉa nhánh vô dụng
// Time: O(2^M) worst case, nhưng pruning giúp Average case ≈ O(K × M × N)
long long solve(int n, int m, int k, vector<Edge>& edges) {
    // Bước 1: Sắp xếp cạnh tăng dần (Greedy heuristic)
    // Sinh cây khung nhỏ trước → Nhanh tìm được K cây nhỏ nhất
    sort(edges.begin(), edges.end());
    
    // multiset: tự động sắp xếp, cho phép trùng lặp
    multiset<long long> all_costs;
    
    // Hàm backtracking với 4 tham số:
    // - idx: chỉ số cạnh đang xét
    // - dsu: trạng thái DSU hiện tại (các đỉnh đã kết nối)
    // - cost: tổng trọng số hiện tại
    // - edges_used: số cạnh đã thêm vào cây
    function<void(int, DSU&, long long, int)> backtrack = 
        [&](int idx, DSU& dsu, long long cost, int edges_used) {
        
        // Base case: Đã có đủ N-1 cạnh → Cây khung hoàn chỉnh
        if (edges_used == n - 1) {
            all_costs.insert(cost);  // Lưu tổng trọng số
            return;
        }
        
        // Pruning 1: Hết cạnh để xét
        if (idx >= m) return;
        
        // Pruning 2: Đã có đủ nhiều cây khung (K × 100 để đảm bảo)
        if (all_costs.size() > k * 100) return;
        
        // Branch 1: THÊM cạnh idx vào cây
        DSU dsu_copy = dsu;  // Copy DSU để backtrack
        if (dsu_copy.unite(edges[idx].u, edges[idx].v)) {  // Kiểm tra chu trình
            // Không tạo chu trình → Thêm được → Tiếp tục đệ quy
            backtrack(idx + 1, dsu_copy, 
                     cost + edges[idx].cost, edges_used + 1);
        }
        // Nếu unite() = false → Tạo chu trình → Bỏ qua nhánh này (implicit pruning)
        
        // Branch 2: BỎ QUA cạnh idx (không thêm vào cây)
        backtrack(idx + 1, dsu, cost, edges_used);
    };
    
    // Bắt đầu backtracking từ cạnh 0, DSU rỗng, cost = 0, chưa có cạnh nào
    DSU initial_dsu(n);
    backtrack(0, initial_dsu, 0, 0);
    
    // Lấy phần tử thứ K trong multiset đã sắp xếp
    auto it = all_costs.begin();
    advance(it, k - 1);  // Di chuyển iterator đến vị trí k-1
    return *it;
}

int main() {
    int n, m, k;
    cin >> n >> m >> k;
    
    vector<Edge> edges(m);
    for (int i = 0; i < m; i++) {
        cin >> edges[i].u >> edges[i].v >> edges[i].cost;
    }
    
    long long result = solve(n, m, k, edges);
    cout << result << endl;
    
    return 0;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(2^M)$ worst case

Tuy nhiên, với pruning:
- Average case: $O(K \times M \times N)$
- Thực tế chạy nhanh hơn nhiều

**Space Complexity:** $O(M + N + K)$

## Nếu cần tối ưu hơn nữa: Phân hoạch tập cạnh (Partitioning Algorithm) kết hợp với Hàng đợi ưu tiên (Priority Queue)

### Phân tích chi tiết
**1. Logic Phân hoạch (Partitioning)**

Thuật toán đảm bảo không bao giờ duyệt trùng một cây khung bằng cách:
- Khi loại bỏ một cạnh $e_i$ khỏi cây khung hiện tại để tìm cây thay thế, ở các bước sau đó, ta ép hệ thống phải dùng lại cạnh $e_i$ đó nhưng loại bỏ cạnh tiếp theo.
- Điều này chia không gian tìm kiếm thành các tập hợp con rời nhau hoàn toàn.

**2. Tại sao tối ưu?**

- **Sử dụng bộ nhớ:** Chỉ lưu trữ các cây khung thực sự hợp lệ vào Priority Queue.
- **Thời gian:** $O(K \cdot M \cdot \text{MST}(N, M))$, trong đó mỗi lần gọi get_mst tốn khoảng $O(M \log M)$ hoặc $O(M \cdot \alpha(N))$.
Thay vì $2^M$, thuật toán chỉ chạy tối đa $K \times M$ lần gọi hàm tìm MST. Với $K$ nhỏ (như đề bài thường cho $K \le 100$), đây là tốc độ ánh sáng so với Backtracking.

### Cài đặt


``` cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <queue>

using namespace std;

struct Edge {
    int u, v, w, id;
    bool operator<(const Edge& other) const { return w < other.w; }
};

struct MST_State {
    long long total_w;
    vector<int> edge_ids;
    vector<int> included, excluded;

    bool operator>(const MST_State& other) const { return total_w > other.total_w; }
};

struct DSU {
    vector<int> parent;
    DSU(int n) {
        parent.resize(n + 1);
        for (int i = 0; i <= n; i++) parent[i] = i;
    }
    int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }
    bool unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return false;
        parent[px] = py;
        return true;
    }
};

// Hàm tìm MST với các ràng buộc cạnh
pair<long long, vector<int>> get_mst(int n, int m, const vector<Edge>& edges, 
                                     const vector<int>& inc, const vector<int>& exc) {
    DSU dsu(n);
    long long weight = 0;
    vector<int> used_edges;
    vector<bool> is_excluded(m, false);
    for (int idx : exc) is_excluded[idx] = true;

    // Ưu tiên các cạnh bắt buộc
    for (int idx : inc) {
        if (!dsu.unite(edges[idx].u, edges[idx].v)) return {-1, {}};
        weight += edges[idx].w;
        used_edges.push_back(idx);
    }

    // Thêm các cạnh còn lại theo thứ tự trọng số
    for (int i = 0; i < m; i++) {
        if (is_excluded[i]) continue;
        bool already_inc = false;
        for(int idx : inc) if(idx == i) already_inc = true;
        if(already_inc) continue;

        if (dsu.unite(edges[i].u, edges[i].v)) {
            weight += edges[i].w;
            used_edges.push_back(i);
        }
    }

    if (used_edges.size() != n - 1) return {-1, {}};
    sort(used_edges.begin(), used_edges.end());
    return {weight, used_edges};
}

int main() {
    int n, m, k;
    cin >> n >> m >> k;
    vector<Edge> edges(m);
    for (int i = 0; i < m; i++) {
        cin >> edges[i].u >> edges[i].v >> edges[i].w;
        edges[i].id = i;
    }
    sort(edges.begin(), edges.end());

    priority_queue<MST_State, vector<MST_State>, greater<MST_State>> pq;
    auto initial = get_mst(n, m, edges, {}, {});
    if (initial.first != -1) {
        pq.push({initial.first, initial.second, {}, {}});
    }

    while (!pq.empty()) {
        MST_State top = pq.top();
        pq.pop();
        k--;

        if (k == 0) {
            cout << top.total_w << endl;
            return 0;
        }

        // Tạo các phân hoạch mới từ cây hiện tại
        vector<int> current_inc = top.included;
        for (int i = 0; i < top.edge_ids.size(); i++) {
            int edge_to_exclude = top.edge_ids[i];
            
            // Kiểm tra xem cạnh này có trong danh sách bắt buộc không
            bool is_mandatory = false;
            for(int idx : top.included) if(idx == edge_to_exclude) is_mandatory = true;
            if (is_mandatory) continue;

            vector<int> new_exc = top.excluded;
            new_exc.push_back(edge_to_exclude);

            auto next_mst = get_mst(n, m, edges, current_inc, new_exc);
            if (next_mst.first != -1) {
                pq.push({next_mst.first, next_mst.second, current_inc, new_exc});
            }
            current_inc.push_back(edge_to_exclude);
        }
    }

    return 0;
}
```

## Tổng Kết

### Quy Trình Giải Quyết

1. **Nhận dạng bài toán:** K-th Minimum Spanning Tree
2. **Kiến thức cơ bản:** DSU, Kruskal's algorithm
3. **Brute force:** Liệt kê tất cả spanning trees
4. **Tối ưu với backtracking:** Sinh có hệ thống + pruning
5. **Phân tích trade-offs:** Time vs Space, completeness vs efficiency

### Key Points

- **Time:** $O(2^M)$ worst case, nhưng pruning giúp chạy nhanh
- **Space:** $O(M + N + K)$
- **DSU:** Cấu trúc quan trọng, $O(\alpha(n)) \approx O(1)$
- **Kruskal:** Nền tảng để tìm MST, $O(M \log M)$

### Câu Hỏi Mở Rộng Có Thể Gặp

**Q: Nếu cần tìm tất cả MST (không chỉ K)?**
- A: Dùng thuật toán đặc biệt như Gabow-Myers, nhưng phức tạp cao

**Q: Prim's algorithm có dùng được không?**
- A: Có, nhưng Kruskal phù hợp hơn với bài này vì dễ backtrack

**Q: Nếu K rất lớn (10^6)?**
- A: Cần thuật toán khác, có thể approximate hoặc sampling

**Q: Làm sao đảm bảo tìm đúng K MST nhỏ nhất?**
- A: Backtracking theo thứ tự cạnh đã sort đảm bảo sinh MST nhỏ trước

**Q: Bài toán liên quan?**
- A: MST variants, Steiner Tree, k-MST, Degree-constrained MST
