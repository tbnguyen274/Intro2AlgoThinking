# Bài 9: Regular Expression Matching

## Đề Bài

Cho 2 chuỗi **s** và **p** gồm các ký tự latin in thường 'a'-'z'. Trong chuỗi **p** có thể có thêm các ký tự đặc biệt với ý nghĩa:

- **Ký tự `*`:** Biểu diễn rằng có thể lặp lại ký tự ngay trước đó một hoặc nhiều lần hoặc có thể không lặp lại lần nào.
  - Ví dụ: Chuỗi `"abbbb"` có thể được sinh ra từ `"ab*"`
  - Chuỗi `"a"` cũng có thể được sinh ra từ `"ab*"` (lặp 'b' 0 lần)

- **Ký tự `.`:** Biểu diễn rằng chỉ có thể thay thế cho một ký tự duy nhất tại vị trí đó.
  - Ví dụ: Chuỗi `"abc"` có thể được sinh ra từ `"a.c"` hoặc `"ab."`

**Yêu cầu:** Kiểm tra xem chuỗi **s** có phải được sinh ra từ chuỗi **p** hay không.

**Dữ liệu vào:**
- Dòng đầu tiên chứa chuỗi **s** (len(s) ≤ 20)
- Dòng thứ hai chứa chuỗi **p** (len(p) ≤ 30)

**Kết quả:**
- Trả về `"true"` nếu chuỗi **s** có thể được sinh ra từ chuỗi **p**
- Trả về `"false"` nếu ngược lại

**Ví dụ:**
```
INPUT:
mississippi
mis*is*p*.

OUTPUT:
false
```

```
INPUT:
aab
c*a*b

OUTPUT:
true
```

## Phân Tích Bài Toán

### Hiểu Đề Bài

Đây là bài toán **Regular Expression Matching** - một bài toán classic và quan trọng trong computer science.

**Ví dụ 1:** s = `"aab"`, p = `"c*a*b"`

Phân tích pattern:
- `"c*"` -> Khớp với 0 lần 'c' -> `""`
- `"a*"` -> Khớp với 2 lần 'a' -> `"aa"`
- `"b"` -> Khớp với 'b' -> `"b"`
- **Kết quả:** `""` + `"aa"` + `"b"` = `"aab"` -> **true**

**Ví dụ 2:** s = `"mississippi"`, p = `"mis*is*p*."`

Phân tích:
- `"mi"` -> Khớp với "mi"
- `"s*"` -> Có thể khớp với "s", "ss", "sss", ...
- `"is*"` -> Có thể khớp với "i", "is", "iss", ...
- `"p*"` -> Có thể khớp với "", "p", "pp", ...
- `"."` -> Khớp với 1 ký tự bất kỳ

Sau khi thử các khả năng -> Không thể khớp hoàn toàn -> **false**

## Approach 1: Recursion - Ý Tưởng Đơn Giản

### Ý Tưởng

**Tư duy tự nhiên khi giải bài toán:**

Khi so khớp chuỗi, ta thường nghĩ theo kiểu "xử lý từng ký tự một". Đệ quy là cách tự nhiên nhất để biểu diễn tư duy này.

**Nguyên tắc cơ bản:**

Tại mỗi bước, xét 3 thành phần:
1. **Ký tự hiện tại của text** (`s[i]`)
2. **Ký tự hiện tại của pattern** (`p[j]`)
3. **Ký tự tiếp theo của pattern** (`p[j+1]` - kiểm tra xem có là `*` không)

**Base cases (trường hợp dừng):**

1. **Pattern rỗng (`j == len(p)`):**
   - Nếu text cũng rỗng (`i == len(s)`) -> khớp -> return `true`
   - Nếu text vẫn còn ký tự -> không khớp -> return `false`

2. **Text rỗng nhưng pattern còn:**
   - Chỉ khớp nếu pattern còn lại toàn là `x*` (khớp 0 lần)
   - Ví dụ: s="", p="a*b*c*" -> khớp (mỗi `x*` khớp 0 lần)

**Recursive logic chi tiết:**

**Bước 1: Kiểm tra ký tự hiện tại**
```
first_match = (i < len(s)) && (s[i] == p[j] || p[j] == '.')
```
- `.` khớp với bất kỳ ký tự nào
- Cần kiểm tra `i < len(s)` để tránh lỗi out of bounds

**Bước 2: Xử lý dựa trên ký tự tiếp theo**

**TH1: Nếu `p[j+1] == '*'` (có dấu sao):**

Có 2 lựa chọn:

- **Option A - Khớp 0 lần:** Bỏ qua `p[j]` và `*`
  ```
  isMatch(s, p, i, j+2)
  ```
  Ví dụ: s="aab", p="c*aab" -> bỏ qua "c*", kiểm tra "aab" với "aab"

- **Option B - Khớp ≥1 lần:** Nếu `first_match`, tiêu thụ một ký tự của s, giữ nguyên pattern
  ```
  first_match && isMatch(s, p, i+1, j)
  ```
  Ví dụ: s="aaa", p="a*" -> tiêu thụ 'a', vẫn còn "aa" với "a*"

- **Kết quả:** `Option A OR Option B` (thử cả 2, chỉ cần 1 cái thành công)

**TH2: Không có `*` (ký tự thường hoặc `.`):**

Bắt buộc phải khớp ký tự hiện tại, rồi tiến cả 2 pointer:
```
first_match && isMatch(s, p, i+1, j+1)
```

**Tại sao approach này "tự nhiên"?**
- Biểu diễn trực tiếp logic so khớp
- Dễ hiểu, dễ chứng minh tính đúng
- Tương tự cách con người nghĩ

**Vấn đề:**
- Tính lặp lại: Cùng một state `(i, j)` bị tính nhiều lần
- Độ phức tạp exponential: $O(2^{n+m})$


```
isMatch(s, p):
    1. Check first_match = (s[0] == p[0]) hoặc (p[0] == '.')
    
    2. Nếu p[1] == '*':
       - Option A: Dùng '*' khớp 0 lần -> isMatch(s, p[2..])
       - Option B: Dùng '*' khớp ≥1 lần -> first_match && isMatch(s[1..], p)
       return (Option A OR Option B)
    
    3. Nếu không có '*':
       return first_match && isMatch(s[1..], p[1..])
```

### Visualization

**Example:** s = `"aab"`, p = `"c*a*b"`

```
isMatch("aab", "c*a*b")
├─ Option A: isMatch("aab", "a*b")     # 'c*' khớp 0 lần
│  ├─ Option A: isMatch("aab", "b")    # 'a*' khớp 0 lần -> false
│  └─ Option B: isMatch("ab", "a*b")   # 'a*' khớp 1 lần
│     └─ Option B: isMatch("b", "a*b") # 'a*' khớp 1 lần nữa
│        └─ Option A: isMatch("b", "b") # 'a*' khớp 0 lần -> true
└─ Option B: first_match = false       # 'a' != 'c'
```

### Code Implementation

```cpp
#include <iostream>
#include <string>
using namespace std;

// Đệ quy kiểm tra s[i..] có khớp với pattern p[j..] không
// i: chỉ số hiện tại trong chuỗi s
// j: chỉ số hiện tại trong pattern p
// Time: O(2^(n+m)) - Exponential, rất chậm
bool isMatchRecursive(const string& s, const string& p, int i, int j) {
    // Base case 1: Pattern đã hết
    if (j == p.length()) {
        // Chỉ khớp nếu chuỗi cũng hết
        return i == s.length();
    }
    
    // Kiểm tra ký tự hiện tại có khớp không
    // Khớp nếu: s[i] == p[j] HOẶC p[j] == '.' (wildcard)
    bool first_match = (i < s.length() &&  // Còn ký tự trong s
                       (s[i] == p[j] || p[j] == '.'));  // Khớp chính xác hoặc wildcard
    
    // Xử lý '*' (zero or more repetitions)
    if (j + 1 < p.length() && p[j + 1] == '*') {
        // Có '*' ngay sau p[j] -> 2 options:
        
        // Option A: Khớp 0 lần - Bỏ qua p[j]* (nhảy qua 2 ký tự trong pattern)
        // Ví dụ: s="ab", p="c*ab" -> bỏ "c*", kiểm tra "ab" vs "ab"
        bool match_zero = isMatchRecursive(s, p, i, j + 2);
        
        // Option B: Khớp ≥1 lần - Nếu first_match, tiêu thụ s[i] và giữ nguyên p[j]*
        // Ví dụ: s="aaa", p="a*" -> dùng 'a' khớp, tiếp "aa" vs "a*"
        bool match_one_or_more = first_match && isMatchRecursive(s, p, i + 1, j);
        
        // Trả về true nếu một trong hai options thành công
        return match_zero || match_one_or_more;
    } 
    // Không có '*': Phải khớp chính xác 1 ký tự
    else {
        // Khớp nếu ký tự hiện tại khớp VÀ phần còn lại cũng khớp
        return first_match && isMatchRecursive(s, p, i + 1, j + 1);
    }
}

int main() {
    string s, p;
    cin >> s >> p;  // Nhập chuỗi và pattern
    
    bool result = isMatchRecursive(s, p, 0, 0);  // Bắt đầu từ đầu cả hai chuỗi
    cout << (result ? "true" : "false") << endl;
    
    return 0;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(2^{n+m})$

- Mỗi lần gặp `*`, có 2 options -> branching factor = 2
- Worst case: Pattern toàn là `x*y*z*...`
- Độ sâu recursion: $n + m$

**Space Complexity:** $O(n + m)$ cho recursion stack

### Đánh Giá

Với len(s) ≤ 20, len(p) ≤ 30:
- Worst case: $2^{50} \approx 10^{15}$ operations
- **TLE (Time Limit Exceeded)!**

**Vấn đề:** Nhiều subproblems bị tính lại nhiều lần.

## Approach 2: Dynamic Programming - Tối Ưu

### Ý Tưởng

**Vấn đề của đệ quy:**

Approach 1 hoạt động đúng nhưng rất chậm vì tính lặp lại subproblems.

**Overlapping Subproblems - Ví dụ cụ thể:**

```
isMatch("aaa", "a*a*")
├─ Option A: skip "a*" -> isMatch("aaa", "a*")
│  ├─ isMatch("aa", "a*")  ← State X
│  └─ isMatch("a", "a*")
└─ Option B: match 'a' -> isMatch("aa", "a*a*")
   ├─ isMatch("aa", "a*")  ← State X (bị tính lại!)
   └─ isMatch("a", "a*a*")
```

State `isMatch("aa", "a*")` bị tính nhiều lần -> lãng phí!

**Giải pháp: Dynamic Programming**

Lưu kết quả cỡc các subproblem, mỗi state chỉ tính 1 lần.

**Định nghĩa State:**

`dp[i][j]` = `true` nếu `s[0..i-1]` khớp với `p[0..j-1]`

- Chỉ số: 1-indexed để dễ xử lý trường hợp rỗng
- Kích thước: `(n+1) × (m+1)` để chứa cả chuỗi rỗng

**Base cases (khởi tạo):**

1. **Cả hai rỗng:**
   ```
   dp[0][0] = true  // "" khớp với ""
   ```

2. **Text rỗng, pattern không rỗng:**
   ```
   dp[0][j] = true nếu p[0..j-1] có thể tạo ra rỗng
   ```
   - Chỉ các cặp `x*` mới tạo ra rỗng
   - Ví dụ: "a*b*c*" -> dp[0][2]=true, dp[0][4]=true, dp[0][6]=true
   - Công thức: `if (p[j-1] == '*') dp[0][j] = dp[0][j-2]`

3. **Pattern rỗng, text không rỗng:**
   ```
   dp[i][0] = false cho mọi i > 0
   ```

**Transition (quy tắc chuyển trạng thái):**

**TH1: `p[j-1]` là ký tự thường hoặc `.`**

Phải khớp ký tự hiện tại:
```
dp[i][j] = dp[i-1][j-1] && (s[i-1] == p[j-1] || p[j-1] == '.')
```

**TH2: `p[j-1]` là `*`**

Có 2 lựa chọn:

- **Option A - Khớp 0 lần:** Bỏ qua `p[j-2]` và `*`
  ```
  dp[i][j] = dp[i][j-2]
  ```
  Ví dụ: "ab" khớp "abc*" -> bỏ "c*", kiểm tra "ab" với "ab"

- **Option B - Khớp ≥1 lần:** Nếu ký tự trước `*` khớp
  ```
  dp[i][j] = dp[i-1][j] && (s[i-1] == p[j-2] || p[j-2] == '.')
  ```
  Ví dụ: "aaa" khớp "a*" -> tiêu thụ 'a', vẫn kiểm tra "aa" với "a*"

- **Kết quả:** `dp[i][j] = Option A || Option B`

**Thứ tự tính toán:**

Duyệt theo thứ tự:
```
for i from 1 to n:
    for j from 1 to m:
        // Tính dp[i][j] dựa trên các giá trị đã tính
```

**Tại sao DP hiệu quả?**
- Mỗi state `(i, j)` chỉ tính **1 lần duy nhất**
- Tổng cộng $(n+1) \times (m+1)$ states
- Mỗi state tính trong $O(1)$
- **Kết quả:** $O(n \times m)$ thay vì $O(2^{n+m})$

### DP Definition

**State:** `dp[i][j]` = `true` nếu `s[0..i-1]` khớp với `p[0..j-1]`

**Dimensions:** `(n+1) × (m+1)` để handle chuỗi rỗng

**Base Cases:**
- `dp[0][0] = true` (chuỗi rỗng khớp với pattern rỗng)
- `dp[0][j]` = `true` nếu `p[0..j-1]` có thể tạo ra rỗng (các cặp `x*`)
- `dp[i][0] = false` nếu `i > 0` (text không rỗng không khớp với pattern rỗng)

**Transition:**

1. **Nếu `p[j-1] != '*'` (ký tự thường hoặc '.'):**
   ```
   dp[i][j] = dp[i-1][j-1] && (s[i-1] == p[j-1] || p[j-1] == '.')
   ```

2. **Nếu `p[j-1] == '*'`:**
   ```
   Option A: Khớp 0 lần -> dp[i][j] = dp[i][j-2]
   Option B: Khớp ≥1 lần -> dp[i][j] = dp[i-1][j] && (s[i-1] == p[j-2] || p[j-2] == '.')
   
   dp[i][j] = Option A OR Option B
   ```

**Tóm tắt:**

Ta dùng **Dynamic Programming** với `dp[i][j]` biểu diễn việc `s[0..i-1]` có khớp `p[0..j-1]` hay không.

Với `*`, xét hai khả năng:
- **khớp 0 lần** (`dp[i][j-2]`), ta bỏ qua ký tự trước đó và chính dấu *, coi như `x*` là rỗng
- **khớp ≥1 lần** nếu ký tự trước đó khớp', ta kiểm tra trạng thái trước đó của xâu $s$ (`dp[i-1][j]`);

Nếu không có `*` thì chỉ khớp khi ký tự hiện tại (hoặc `.`) trùng và kế thừa từ `dp[i-1][j-1]`.

### DP Table Example

**Input:** s = `"aab"`, p = `"c*a*b"`

|     | ε | c | c* | a | a* | b |
|-----|---|---|----|---|----|---|
| **ε** | T | F | T  | F | T  | F |
| **a** | F | F | F  | T | T  | F |
| **a** | F | F | F  | F | T  | F |
| **b** | F | F | F  | F | F | **T** |

**Giải thích từng bước:**

1. **Row 0 (ε):**
   - `dp[0][0] = T` (base)
   - `dp[0][2] = T` (`"c*"` khớp với rỗng)
   - `dp[0][4] = T` (`"c*a*"` khớp với rỗng)

2. **Row 1 (a):**
   - `dp[1][3] = T` (`"a"` khớp với `"c*a"`)
   - `dp[1][4] = T` (`"a"` khớp với `"c*a*"`)

3. **Row 2 (aa):**
   - `dp[2][4] = T` (`"aa"` khớp với `"c*a*"`)

4. **Row 3 (aab):**
   - `dp[3][5] = T` (`"aab"` khớp với `"c*a*b"`)

**Result:** `dp[3][5] = true`

### Code Implementation

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

// Dynamic Programming Solution
// dp[i][j] = s[0..i-1] có khớp với p[0..j-1] không
// Time: O(n × m), Space: O(n × m)
bool isMatch(const string& s, const string& p) {
    int n = s.length();  // Độ dài chuỗi
    int m = p.length();  // Độ dài pattern
    
    // Khởi tạo bảng DP: (n+1) × (m+1), mặc định false
    // dp[i][j]: s[0..i-1] khớp với p[0..j-1]
    vector<vector<bool>> dp(n + 1, vector<bool>(m + 1, false));
    
    // Base case 1: Chuỗi rỗng khớp với pattern rỗng
    dp[0][0] = true;
    
    // Base case 2: Chuỗi rỗng có thể khớp với pattern có dạng "a*b*c*..."
    // Ví dụ: "" khớp với "a*", "a*b*", ".*" (khớp 0 lần)
    for (int j = 1; j <= m; j++) {
        if (p[j - 1] == '*') {
            // '*' phụ thuộc vào ký tự trước nó
            if (j >= 2) {
                // Khớp 0 lần: Bỏ qua cặp "x*" (2 ký tự)
                dp[0][j] = dp[0][j - 2];
            }
            // Nếu '*' ở đầu (j < 2), giữ nguyên false (không hợp lệ)
        }
        // Nếu p[j-1] không phải '*', dp[0][j] = false (chuỗi rỗng không khớp ký tự thường)
    }
    
    // Lấp đầy bảng DP
    for (int i = 1; i <= n; i++) {         // Duyệt chuỗi s
        for (int j = 1; j <= m; j++) {     // Duyệt pattern p
            
            if (p[j - 1] == '*') {
                // Xử lý '*': zero or more của ký tự trước nó (p[j-2])
                if (j >= 2) {
                    // Option A: Khớp 0 lần - Bỏ qua "x*" (lùi 2 ký tự trong pattern)
                    dp[i][j] = dp[i][j - 2];

                    // Option B: Khớp ≥1 lần - Nếu ký tự hiện tại khớp
                    // Kiểm tra: s[i-1] khớp với p[j-2] (ký tự trước '*')
                    if (s[i - 1] == p[j - 2] || p[j - 2] == '.') {
                        // Tiêu thụ s[i-1], giữ pattern (có thể dùng '*' tiếp)
                        dp[i][j] = dp[i][j] || dp[i - 1][j];
                    }
                }
            } 
            // Không có '*': Khớp ký tự đơn (s[i-1] vs p[j-1])
            else {
                // Kiểm tra ký tự khớp: chính xác hoặc wildcard '.'
                if (s[i - 1] == p[j - 1] || p[j - 1] == '.') {
                    // Khớp nếu phần trước đó cũng khớp
                    dp[i][j] = dp[i - 1][j - 1];
                }
                // Nếu không khớp, dp[i][j] giữ nguyên false
            }
        }
    }
    
    // Kết quả: Toàn bộ chuỗi s có khớp với toàn bộ pattern p không
    return dp[n][m];
}

int main() {
    string s, p;
    cin >> s >> p;
    
    bool result = isMatch(s, p);
    cout << (result ? "true" : "false") << endl;
    
    return 0;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(n \times m)$

- Fill bảng DP: $(n+1) \times (m+1)$ cells
- Mỗi cell: $O(1)$ operations

**Space Complexity:** $O(n \times m)$ cho DP table

### Đánh Giá

Với n ≤ 20, m ≤ 30:
- $O(20 \times 30) = 600$ operations
- **Hoàn toàn OK! Đảm bảo mọi test case**

## Approach 3: Space Optimization

### Quan Sát

DP chỉ cần 2 rows (current và previous) để tính toán.

**Optimized Space:** $O(\min(n, m))$

Tuy nhiên, với n ≤ 20, m ≤ 30, không cần tối ưu thêm.

### Implementation

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

bool isMatch(const string& s, const string& p) {
    int n = s.length();
    int m = p.length();
    
    // Chỉ cần 2 hàng: hàng hiện tại (curr) và hàng trước đó (prev)
    vector<bool> prev(m + 1, false);
    vector<bool> curr(m + 1, false);
    
    // Trạng thái cơ bản: xâu rỗng khớp với pattern rỗng
    prev[0] = true;
    
    // Khởi tạo hàng 0 cho prev (khi s rỗng)
    for (int j = 1; j <= m; j++) {
        if (p[j - 1] == '*') {
            if (j >= 2) prev[j] = prev[j - 2];
        }
    }
    
    for (int i = 1; i <= n; i++) {
        // s[0...i-1] không bao giờ khớp với pattern rỗng (p="")
        curr[0] = false; 
        
        for (int j = 1; j <= m; j++) {
            if (p[j - 1] == '*') {
                if (j >= 2) {
                    // Trường hợp không lấy ký tự trước dấu *
                    curr[j] = curr[j - 2]; 
                    
                    // Trường hợp lấy ít nhất 1 ký tự (dựa vào hàng prev)
                    if (s[i - 1] == p[j - 2] || p[j - 2] == '.') {
                        curr[j] = curr[j] || prev[j];
                    }
                }
            } else {
                // Khớp ký tự thường hoặc dấu '.'
                if (s[i - 1] == p[j - 1] || p[j - 1] == '.') {
                    curr[j] = prev[j - 1];
                } else {
                    curr[j] = false; // Quan trọng: reset lại giá trị hàng hiện tại
                }
            }
        }
        // Sau mỗi dòng, hàng hiện tại trở thành hàng trước đó cho bước sau
        prev = curr;
        // Reset curr để dùng cho vòng lặp i tiếp theo
        fill(curr.begin(), curr.end(), false);
    }
    
    return prev[m];
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    string s, p;
    if (!getline(cin, s)) s = "";
    if (!getline(cin, p)) p = "";
    
    cout << (isMatch(s, p) ? "true" : "false") << endl;
    
    return 0;
}
```

## Tổng Kết

### Quy Trình Giải Quyết

1. **Nhận dạng bài toán:** Regular Expression Matching - bài toán classic
2. **Recursion first:** Giải pháp đơn giản, dễ hiểu
3. **Nhận ra vấn đề:** Exponential time complexity
4. **Tối ưu với DP:** Memoization hoặc bottom-up table
5. **Giải thích state transition:** Xử lý '*' và '.' chi tiết
6. **Phân tích edge cases:** Pattern rỗng, text rỗng, `x*`, `.*`

### Key Points

- **Time:** $O(n \times m)$ với DP
- **Space:** $O(n \times m)$ cho DP table
- **Critical insight:** `*` luôn đi kèm với ký tự trước đó
- **Two options for `*`:** Khớp 0 lần hoặc ≥1 lần

### Câu Hỏi Mở Rộng Có Thể Gặp

**Q: Nếu thêm ký tự '+' (khớp ≥1 lần, không được 0 lần)?**
- A: Tương tự `*` nhưng loại bỏ option "khớp 0 lần"

**Q: Nếu thêm ký tự '?' (optional, khớp 0 hoặc 1 lần)?**
- A: `dp[i][j] = dp[i][j-1] || (match && dp[i-1][j-1])`

**Q: Space complexity có thể giảm không?**
- A: Có, dùng 2 arrays thay vì full table -> $O(\min(n,m))$

**Q: Có thể dùng NFA (Non-deterministic Finite Automaton) không?**
- A: Có, nhưng phức tạp hơn và cùng độ phức tạp $O(nm)$

**Q: Bài toán liên quan?**
- A: Wildcard Matching (LeetCode 44), String to Integer (atoi), Parse Boolean Expression
