# Bài 13: Tìm Đường Thẳng Chia Đều Các Điểm

## Đề Bài

Trong mặt phẳng cho **n** điểm ($n \leq 10^3$) có tọa độ nguyên sao cho:
- Không có 2 điểm nào trùng nhau
- Không có 3 điểm nào thẳng hàng
- **n** là một số chẵn

**Yêu cầu:** Hãy chọn ra 2 điểm trong số n điểm để đường thẳng qua 2 điểm này chia tập điểm thành 2 phần có số lượng điểm bằng nhau.

**Dữ liệu vào:**
- Dòng đầu tiên: $n$ ($2 \leq n \leq 10^3$)
- Dòng thứ $i$ trong $n$ dòng tiếp theo: $x_i, y_i$ ($|x_i|, |y_i| \leq 10^6$) – tọa độ của điểm thứ $i$

**Kết quả:**
- Gồm 2 số là số thứ tự của 2 điểm được chọn

**Ví dụ:**
```
INPUT:
6
3 5
1 3
3 1
6 1
8 3
6 5

OUTPUT:
2 5
```

---

## Phân Tích Bài Toán

### Hiểu Đề Bài

Đây là bài toán **Computational Geometry** - tìm đường chia (ham sandwich cut).

**Ví dụ:** 6 điểm

```
       (3,5)         (6,5)
         1             6
         
   (1,3)-----------(8,3)
     2        y=3       5
     
       (3,1)         (6,1)
         3             4
```

Đường thẳng qua điểm 2 `(1,3)` và điểm 5 `(8,3)` là đường ngang $y = 3$.

**Phân chia:**
- **Phía trên** (y > 3): Điểm 1, 6 → 2 điểm
- **Trên đường** (y = 3): Điểm 2, 5 → 2 điểm
- **Phía dưới** (y < 3): Điểm 3, 4 → 2 điểm

Mỗi nửa có **2 điểm** → **Chia đều!**

### Định Nghĩa "Chia Đều"

Đường thẳng qua 2 điểm A và B chia đều nếu:
- Số điểm bên trái = Số điểm bên phải = $\frac{n-2}{2}$
- Hoặc: Mỗi nửa có $\frac{n}{2}$ điểm (tính cả 2 điểm trên đường)

## Approach 1: Brute Force - Kiểm Tra Tất Cả

### Ý Tưởng

**Bài toán hình học: Ham Sandwich Cut**

Tìm đường thẳng qua 2 điểm sao cho chia đều các điểm còn lại thành 2 phía.

**Các bước thực hiện:**

**Bước 1: Liệt kê tất cả cặp điểm**
- Với $n$ điểm, có $\binom{n}{2} = \frac{n(n-1)}{2}$ cặp
- Mỗi cặp định nghĩa duy nhất một đường thẳng
- Ví dụ: 6 điểm → $\frac{6 \times 5}{2} = 15$ cặp cần kiểm tra

**Bước 2: Với mỗi cặp (A, B), tạo đường thẳng**
Đường thẳng AB chia mặt phẳng thành 3 vùng:
- **Bên trái:** Các điểm nằm về một phía
- **Trên đường:** Các điểm thẳng hàng với A, B (không có theo đề)
- **Bên phải:** Các điểm nằm phía còn lại

**Bước 3: Đếm điểm mỗi bên bằng Cross Product**

**Tại sao dùng Cross Product?**

Cross product cho biết vị trí tương đối của điểm so với đường thẳng:

**Công thức:**
$$\text{cross}(A, B, P) = (B_x - A_x)(P_y - A_y) - (B_y - A_y)(P_x - A_x)$$

**Ý nghĩa hình học:**
- `cross > 0`: P nằm **bên trái** đường thẳng AB (ngược chiều kim đồng hồ)
- `cross < 0`: P nằm **bên phải** đường thẳng AB (thuận chiều kim đồng hồ)
- `cross = 0`: P nằm **trên đường thẳng** AB (thẳng hàng)

**Quy tắc tay phải (Right-hand rule):**
- Ngón trỏ: hướng từ A đến B
- Ngón giữa: hướng từ A đến P
- Ngón cái: hướng của cross product
  - Hướng ra ngoài (dương) → bên trái
  - Hướng vào trong (âm) → bên phải

**Ví dụ cụ thể:**
```
A(1,3), B(8,3), P(3,5)

cross = (8-1)(5-3) - (3-3)(3-1)
      = 7 × 2 - 0 × 2
      = 14 > 0
→ P nằm bên trái (phía trên đường nằm ngang)
```

**Bước 4: Kiểm tra điều kiện chia đều**

Duyệt qua $n-2$ điểm còn lại (không kể A và B):
- Đếm `left_count`: số điểm có cross > 0
- Đếm `right_count`: số điểm có cross < 0

**Điều kiện thành công:**
```
left_count == right_count == (n-2)/2
```

Ví dụ: $n=6$ → cần `left_count = right_count = 2`

**Tại sao approach này hiệu quả?**
- Đơn giản, không cần kiến thức hình học phức tạp
- Cross product: phép toán cơ bản, nhanh, chính xác
- Đảm bảo tìm thấy nếu tồn tại
- Với $n \leq 1000$, $O(n^3)$ hoàn toàn chấp nhận được

### Cross Product - Xác Định Vị Trí Điểm

**Công thức:**

Đường thẳng từ $A(x_1, y_1)$ đến $B(x_2, y_2)$  
Điểm $P(x, y)$

$$\text{cross} = (x_2 - x_1)(y - y_1) - (y_2 - y_1)(x - x_1)$$

*(Ghi chú: tương tự tính chất phương trình đường thẳng tổng quát)*

**Ý nghĩa:**
- $\text{cross} > 0$: P nằm **bên trái** đường thẳng AB
- $\text{cross} < 0$: P nằm **bên phải** đường thẳng AB
- $\text{cross} = 0$: P nằm **trên** đường thẳng AB (không xảy ra theo đề)

### Visualization

**Example:** Đường thẳng từ A(1,3) đến B(8,3), kiểm tra P(3,5)

```
        P(3,5)
          ↑
          |
A(1,3) ------→ B(8,3)
```

Vector $\overrightarrow{AB} = (7, 0)$  
Vector $\overrightarrow{AP} = (2, 2)$

$$\text{cross} = 7 \times 2 - 0 \times 2 = 14 > 0$$

→ P nằm **bên trái** AB (phía trên)

**Quy tắc tay phải (3D analogy):**
- Ngón trỏ: hướng AB
- Ngón giữa: hướng AP
- Ngón cái: hướng cross product (ra khỏi màn hình nếu > 0)

### Code Implementation

**Tóm tắt:**
Đoạn code **duyệt mọi cặp điểm (A, B)**, coi đường thẳng AB làm ranh giới và dùng **tích có hướng (cross product)** để đếm số điểm nằm mỗi phía.
Nếu hai phía có **số điểm bằng nhau** (mỗi bên $\frac{n-2}{2}$), thì AB là đường thẳng chia đều và trả về chỉ số hai điểm đó.


```cpp
#include <iostream>
#include <vector>
using namespace std;

struct Point {
    long long x, y;  // Toạ độ điểm
    int index;       // Chỉ số gốc (1-indexed) để output
};

// Cross Product (Tích có hướng): Xác định vị trí tương đối của điểm P so với đường thẳng AB
// Return > 0: P nằm bên trái AB (ngược chiều kim đồng hồ)
// Return < 0: P nằm bên phải AB (thuận chiều kim đồng hồ)
// Return = 0: P nằm trên đường thẳng AB (thẳng hàng)
long long crossProduct(const Point& A, const Point& B, const Point& P) {
    // Công thức: (B - A) × (P - A)
    // = (B.x - A.x) * (P.y - A.y) - (B.y - A.y) * (P.x - A.x)
    return (B.x - A.x) * (P.y - A.y) - (B.y - A.y) * (P.x - A.x);
}

// Kiểm tra đường thẳng qua A và B có chia đều các điểm còn lại không
// Return true nếu mỗi phía có đúng (n-2)/2 điểm
bool checkDivide(const vector<Point>& points, int idxA, int idxB) {
    int n = points.size();
    int left_count = 0;   // Đếm điểm bên trái
    int right_count = 0;  // Đếm điểm bên phải
    
    const Point& A = points[idxA];
    const Point& B = points[idxB];
    
    // Duyệt qua tất cả các điểm (trừ A và B)
    for (int i = 0; i < n; i++) {
        if (i == idxA || i == idxB) continue;  // Bỏ qua A và B
        
        // Tính cross product để xác định vị trí
        long long cross = crossProduct(A, B, points[i]);
        
        if (cross > 0) left_count++;       // Bên trái
        else if (cross < 0) right_count++; // Bên phải
        // Nếu cross == 0: điểm thẳng hàng (theo đề, không xảy ra)
    }
    
    // Điều kiện chia đều: 2 phía bằng nhau VÀ bằng (n-2)/2
    return (left_count == right_count) && (left_count == (n - 2) / 2);
}

// Tìm cặp điểm tạo thành đường thẳng chia đều
// Time: O(n^3) - Duyệt O(n^2) cặp, mỗi cặp kiểm tra O(n) điểm
pair<int, int> findDividingLine(vector<Point>& points) {
    int n = points.size();
    
    // Duyệt qua tất cả các cặp điểm (i, j)
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {  // j > i để tránh trùng lặp
            // Kiểm tra xem đường thẳng i-j có chia đều không
            if (checkDivide(points, i, j)) {
                // Tìm thấy! Trả về chỉ số gốc (1-indexed)
                return {points[i].index, points[j].index};
            }
        }
    }
    
    // Không tìm thấy (theo đề, luôn tồn tại)
    return {-1, -1};
}

int main() {
    int n;
    cin >> n;  // Số điểm (luôn chẵn, ≥6)
    
    vector<Point> points(n);
    for (int i = 0; i < n; i++) {
        cin >> points[i].x >> points[i].y;
        points[i].index = i + 1;  // Lưu chỉ số gốc (1-indexed)
    }
    
    // Tìm đường thẳng chia đều
    pair<int, int> result = findDividingLine(points);
    
    // In kết quả
    cout << result.first << " " << result.second << endl;
    
    return 0;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(n^3)$

- Số cặp điểm: $\binom{n}{2} = \frac{n(n-1)}{2} \approx O(n^2)$
- Mỗi cặp: Kiểm tra $n-2$ điểm còn lại → $O(n)$
- Tổng: $O(n^2) \times O(n) = O(n^3)$

**Space Complexity:** $O(n)$ để lưu điểm

### Đánh Giá

Với $n \leq 1000$:
- $O(1000^3) = 10^9$ operations
- Mỗi operation đơn giản (phép nhân, cộng)
- **Chạy trong khoảng 1-2 giây → Chấp nhận được!**

## Approach 2: Có Thể Tối Ưu Hơn?

Cách tối ưu nhất cho bài toán này là sử dụng kỹ thuật Sắp xếp góc (Angular Sweep) quanh một điểm gốc. Phương pháp này giúp giảm độ phức tạp từ $O(N^3)$ xuống $O(N^2 \log N)$.

### Tóm tắt ý tưởng tối ưu
- Cố định một điểm gốc $A$: Duyệt qua từng điểm $i$ trong tập hợp.
- Sắp xếp các điểm còn lại: Với mỗi điểm $A$ cố định, ta sắp xếp $N-1$ điểm còn lại theo góc quay quanh $A$.
- Chọn điểm đối diện: Trong danh sách đã sắp xếp, điểm ở vị trí "giữa" (vị trí thứ $N/2$) chắc chắn sẽ tạo với $A$ một đường thẳng chia đôi tập điểm, vì các điểm còn lại được phân bố đều theo thứ tự góc.

### Giải thuật chi tiết $O(N^2 \log N)$
- Duyệt qua điểm $i$ từ $0 \dots N-1$ (gọi là điểm $A$).
- Tạo một mảng các điểm còn lại $P'$.
- Sắp xếp $P'$ theo góc cực so với $A$. Cách chính xác nhất là dùng hàm atan2(y, x) hoặc dùng tích có hướng để so sánh góc mà không cần dùng số thực.
- Lấy điểm $B$ là điểm ở vị trí (N-2) / 2 trong mảng $P'$ đã sắp xếp.
- Đường thẳng $AB$ chính là đáp án cần tìm.

### Cài đặt

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
#include <cmath>

using namespace std;

struct Point {
    long long x, y;  // Toạ độ điểm
    int index;       // Chỉ số gốc (1-indexed)
};

// Biến toàn cục lưu điểm gốc cho hàm so sánh
Point origin;

// Hàm so sánh góc cực của các điểm so với điểm gốc O
// Sắp xếp các điểm theo góc quay ngược chiều kim đồng hồ từ O
// atan2(y, x): trả về góc từ -π đến π
bool compareAngles(const Point& a, const Point& b) {
    // Tính góc của vector (O → a) và (O → b)
    double angle_a = atan2(a.y - origin.y, a.x - origin.x);
    double angle_b = atan2(b.y - origin.y, b.x - origin.x);
    return angle_a < angle_b;  // Sắp xếp theo góc tăng dần
}

int main() {
    // Tối ưu nhập xuất
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n;
    if (!(cin >> n)) return 0;

    vector<Point> points(n);
    for (int i = 0; i < n; i++) {
        cin >> points[i].x >> points[i].y;
        points[i].index = i + 1;  // Lưu chỉ số gốc
    }

    // Chọn một điểm bất kỳ làm gốc (ví dụ: điểm đầu tiên)
    // Thuật toán: Với bất kỳ điểm gốc nào, đều tồn tại đường thẳng chia đều
    for (int i = 0; i < n; i++) {
        origin = points[i];  // Chọn điểm thứ i làm gốc
        
        // Lấy tất cả các điểm khác (trừ origin)
        vector<Point> others;
        for (int j = 0; j < n; j++) {
            if (i == j) continue;  // Bỏ qua điểm gốc
            others.push_back(points[j]);
        }

        // Sắp xếp các điểm khác theo góc quay quanh origin
        // Sau khi sắp xếp: các điểm thứ tự theo chiều ngược kim đồng hồ
        sort(others.begin(), others.end(), compareAngles);

        // Điểm ở vị trí chính giữa sẽ chia tập điểm thành 2 phần bằng nhau
        // Vì n là số chẵn, (n-2) điểm còn lại, mỗi bên (n-2)/2 điểm
        // Ví dụ: n=6 → 4 điểm còn lại → lấy điểm thứ 2 (index = 2)
        int mid = (n - 2) / 2;
        
        // Đường thẳng (origin, others[mid]) chia đều các điểm
        // Trả về kết quả ngay lập tức
        cout << origin.index << " " << others[mid].index << endl;
        return 0;
    }

    return 0;
}
```

## Tổng Kết Phỏng Vấn

### Quy Trình Giải Quyết

1. **Nhận dạng bài toán:** Computational Geometry - Ham Sandwich Cut
2. **Brute force approach:** Thử tất cả cặp điểm
3. **Cross product technique:** Xác định vị trí điểm so với đường thẳng
4. **Phân tích độ phức tạp:** $O(n^3)$ chấp nhận được với $n \leq 1000$
5. **Thảo luận optimization:** Angular sweep

### Key Points

- **Time:** $O(n^3)$ - optimal cho problem size này
- **Space:** $O(n)$
- **Cross Product:** Công cụ quan trọng trong computational geometry
- **Long Long:** Cần thiết để tránh overflow ($10^6 \times 10^6 = 10^{12}$)

### Câu Hỏi Mở Rộng Có Thể Gặp

**Q: Nếu có 3 điểm thẳng hàng thì xử lý như thế nào?**
- A: Cross product = 0, cần xử lý riêng. Có thể đếm điểm trên đường vào 1 bên hoặc chia đều 2 bên, hoặc skip cặp đó để tìm cặp khác.

**Q: Nếu n rất lớn (10^6)?**
- A: Cần thuật toán tối ưu hơn như randomized algorithm hoặc sweep line. Có thể chấp nhận approximate solution.

**Q: Nếu cho nhiều đáp án, chọn cái nào?**
- A: Đề bài yêu cầu 1 đáp án bất kỳ. Có thể chọn cặp có index nhỏ nhất hoặc đường thẳng gần nhất với trọng tâm.

**Q: Overflow khi tính cross product?**
- A: Dùng `long long`. Worst case: $(10^6 - (-10^6)) \times (10^6 - (-10^6)) = 4 \times 10^{12}$ < $2^{63}-1$

**Q: Bài toán liên quan?**
- A: Convex Hull, Line Sweep, Closest Pair of Points, Rotating Calipers
