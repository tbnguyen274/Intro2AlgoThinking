# Bài 5: Tìm Tất Cả Vị Trí Xuất Hiện Của Xâu B Trong Xâu A

## Đề Bài

Cho xâu A và xâu B chỉ gồm các chữ cái thường. Xâu B được gọi là xuất hiện tại vị trí $i$ của xâu A nếu:

$$A_i = B_1, A_{i+1} = B_2, \ldots, A_{i+\text{len}(B)-1} = B_{\text{len}(B)}$$

**Yêu cầu:** Hãy tìm tất cả các vị trí mà xâu B xuất hiện trong A.

**Dữ liệu vào:**
- Dòng 1: xâu A
- Dòng 2: xâu B
- Độ dài A, B không quá $10^6$

**Kết quả:**
- Ghi ra các vị trí tìm được trên 1 dòng (thứ tự tăng dần)
- Nếu B không xuất hiện trong A thì bỏ trắng

**Ví dụ:**
```
INPUT:
aaaaa
aa

OUTPUT:
1 2 3 4
```

---

## Phân Tích Bài Toán

### Hiểu Đề Bài

Đây là bài toán **Pattern Matching** (String Searching) classic.

**Ví dụ:** A = `"aaaaa"`, B = `"aa"`

Các vị trí B xuất hiện trong A:
- Vị trí 1: `"aa"` → A[0..1] = "aa"
- Vị trí 2: `"aa"` → A[1..2] = "aa"
- Vị trí 3: `"aa"` → A[2..3] = "aa"
- Vị trí 4: `"aa"` → A[3..4] = "aa"

Output: `1 2 3 4`

**Lưu ý:** Vị trí đếm từ 1 (1-indexed), không phải 0.

---

## Approach 1: Brute Force - Ý Tưởng Đơn Giản Nhất

### Ý Tưởng

Cách đơn giản nhất:

1. **Duyệt qua từng vị trí** trong A có thể chứa B
2. **Tại mỗi vị trí $i$:** So sánh từng ký tự của B với substring A[i..i+m-1]
3. **Nếu khớp hoàn toàn:** Lưu vị trí $i+1$ (do đếm từ 1)

### Visualization

```
A = "a b c a b c a b c"
     0 1 2 3 4 5 6 7 8

B = "a b c"

Vị trí 0: [a b c] a b c a b c ✓ => Output: 1
Vị trí 1:  a [b c a] b c a b c ✗
Vị trí 2:  a b [c a b] c a b c ✗
Vị trí 3:  a b c [a b c] a b c ✓ => Output: 4
Vị trí 4:  a b c a [b c a] b c ✗
Vị trí 5:  a b c a b [c a b] c ✗
Vị trí 6:  a b c a b c [a b c] ✓ => Output: 7
```

### Code Implementation

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

vector<int> bruteForce(const string& A, const string& B) {
    vector<int> result;
    int n = A.length();
    int m = B.length();
    
    if (m > n) return result;
    
    // Duyệt qua từng vị trí có thể
    for (int i = 0; i <= n - m; i++) {
        bool match = true;
        
        // So sánh B với substring A[i..i+m-1]
        for (int j = 0; j < m; j++) {
            if (A[i + j] != B[j]) {
                match = false;
                break;
            }
        }
        
        if (match) {
            result.push_back(i + 1); // Vị trí đếm từ 1
        }
    }
    
    return result;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(n \times m)$

- Số vị trí cần kiểm tra: $n - m + 1 \approx O(n)$
- Mỗi vị trí: So sánh tối đa $m$ ký tự
- Worst case: Mỗi vị trí so sánh hết $m$ ký tự mới fail

**Space Complexity:** $O(1)$ (không tính output)




## Approach 2: KMP Algorithm - Tối Ưu

### Ý Tưởng

**Knuth-Morris-Pratt (KMP)** - Algorithm cải tiến pattern matching.

**Quan sát chính:**

Khi mismatch xảy ra, không cần quay lại từ đầu. Sử dụng thông tin đã so sánh để skip các vị trí không cần thiết.

**Ví dụ minh họa:**

```
A = "abcabcabc"
B = "abcabd"

Brute force:
Vị trí 0: abcab[c] != abcab[d] (mismatch tại B[5])
          => Quay lại vị trí 1, bắt đầu lại
          
KMP insight:
- Đã khớp "abcab" (5 ký tự)
- Biết rằng "ab" ở cuối phần khớp cũng xuất hiện ở đầu pattern
- Có thể skip, không cần so sánh lại "ab"
```

### LPS Array (Longest Proper Prefix which is also Suffix)

**Định nghĩa:** `lps[i]` = độ dài của proper prefix dài nhất của `pattern[0..i]` mà cũng là suffix của `pattern[0..i]` (không tính chính nó).

**Proper prefix:** Prefix không bao gồm chính xâu đó.

**Ví dụ 1:** Pattern = `"aaaa"`

| i | pattern[0..i] | Proper Prefixes | Proper Suffixes | LPS |
|---|---------------|-----------------|-----------------|-----|
| 0 | "a"           | []              | []              | 0   |
| 1 | "aa"          | ["a"]           | ["a"]           | 1   |
| 2 | "aaa"         | ["a", "aa"]     | ["a", "aa"]     | 2   |
| 3 | "aaaa"        | ["a", "aa", "aaa"] | ["a", "aa", "aaa"] | 3   |

LPS = `[0, 1, 2, 3]`

**Ví dụ 2:** Pattern = `"abcabc"`

| i | pattern[0..i] | Longest Proper Prefix = Suffix | LPS |
|---|---------------|-------------------------------|-----|
| 0 | "a"           | -                             | 0   |
| 1 | "ab"          | -                             | 0   |
| 2 | "abc"         | -                             | 0   |
| 3 | "abca"        | "a"                           | 1   |
| 4 | "abcab"       | "ab"                          | 2   |
| 5 | "abcabc"      | "abc"                         | 3   |

LPS = `[0, 0, 0, 1, 2, 3]`

### Build LPS Array

**Trường hợp 1:** Khớp ký tự ``(if pattern[i] == pattern[len])``

- Ký tự hậu tố đang xét khớp với ký tự tiếp theo của tiền tố
- Ta mở rộng được độ dài chuỗi khớp thêm 1 đơn vị

**Trường hợp 2:** Không khớp
- Nếu trước đó đã khớp được đoạn dài `len != 0`:
    -  Ta không muốn bắt đầu lại từ đầu chuỗi mà sẽ tìm một tiền tố ngắn hơn nằm bên trong tiền tố vừa khớp, sao cho nó vẫn khớp với hậu tố hiện tại
    - Giá trị `lps[len-1]` cho ta biết: "Trong đoạn tiền tố vừa khớp (độ dài `len`), đoạn đầu và đoạn cuối trùng nhau dài bao nhiêu?". Ta nhảy len về vị trí đó để tiếp tục so sánh với `pattern[i]`.
- Nếu `len == 0`: Không có tiền tố nào khớp với hậu tố kết thúc tại i. Gán `lps[i] = 0` và đi tiếp sang ký tự sau.

```cpp
vector<int> buildLPS(const string& pattern) {
    int m = pattern.length();
    vector<int> lps(m, 0);
    
    int len = 0; // Độ dài của previous longest prefix suffix
    int i = 1;
    
    while (i < m) {
        if (pattern[i] == pattern[len]) {
            len++;
            lps[i] = len;
            i++;
        } else {
            if (len != 0) {
                len = lps[len - 1];
                // Không tăng i, thử lại với len mới
            } else {
                lps[i] = 0;
                i++;
            }
        }
    }
    
    return lps;
}
```

**Time:** $O(m)$ - Mỗi ký tự xử lý một lần

### KMP Search

Hàm duyệt mảng `A` một lần duy nhất, khi gặp ký tự không khớp, nó dùng mảng `lps` để biết cần lùi `j` về đâu an toàn nhất mà không cần so sánh lại từ đầu.

```cpp
vector<int> kmpSearch(const string& A, const string& B) {
    vector<int> result;
    int n = A.length();
    int m = B.length();
    
    if (m > n || m == 0) return result;
    
    // Build LPS array
    vector<int> lps = buildLPS(B);
    
    int i = 0; // Index cho A
    int j = 0; // Index cho B
    
    while (i < n) {
        if (A[i] == B[j]) {
            i++;
            j++;
        }
        
        if (j == m) {
            // Tìm thấy pattern tại vị trí i - j
            result.push_back(i - j + 1); // +1 vì đếm từ 1
            j = lps[j - 1];
        } else if (i < n && A[i] != B[j]) {
            if (j != 0) {
                j = lps[j - 1]; // Không quay lại i, chỉ lùi j
            } else {
                i++;
            }
        }
    }
    
    return result;
}
```

### Simulation

**Input:** A = `"aaaaa"`, B = `"aa"`

**Step 1:** Build LPS
- B = "aa"
- LPS = `[0, 1]`

**Step 2:** Search

| Step | i | j | A[i] | B[j] | Action | Found? | j after |
|------|---|---|------|------|--------|--------|---------|
| 1    | 0 | 0 | 'a' | 'a' | Match | - | 1 |
| 2    | 1 | 1 | 'a' | 'a' | Match, j==2 | Position 1 | lps[1]=1 |
| 3    | 2 | 1 | 'a' | 'a' | Match, j==2 | Position 2 | lps[1]=1 |
| 4    | 3 | 1 | 'a' | 'a' | Match, j==2 | Position 3 | lps[1]=1 |
| 5    | 4 | 1 | 'a' | 'a' | Match, j==2 | Position 4 | lps[1]=1 |
| 6    | 5 | - | - | - | i >= n, Done | - | - |

**Output:** `1 2 3 4`

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(n + m)$

- Build LPS: $O(m)$
- Search: $O(n)$
  - Pointer $i$ chỉ tăng, không lùi: $O(n)$
  - Pointer $j$ có thể lùi nhưng tổng số lần lùi $\leq n$: $O(n)$

**Space Complexity:** $O(m)$ cho LPS array

## Solution Cuối Cùng

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

vector<int> buildLPS(const string& pattern) {
    int m = pattern.length();
    vector<int> lps(m, 0);
    
    int len = 0;
    int i = 1;
    
    while (i < m) {
        if (pattern[i] == pattern[len]) {
            len++;
            lps[i] = len;
            i++;
        } else {
            if (len != 0) {
                len = lps[len - 1];
            } else {
                lps[i] = 0;
                i++;
            }
        }
    }
    
    return lps;
}

vector<int> kmpSearch(const string& A, const string& B) {
    vector<int> result;
    int n = A.length();
    int m = B.length();
    
    if (m > n || m == 0) return result;
    
    vector<int> lps = buildLPS(B);
    
    int i = 0;
    int j = 0;
    
    while (i < n) {
        if (A[i] == B[j]) {
            i++;
            j++;
        }
        
        if (j == m) {
            result.push_back(i - j + 1);
            j = lps[j - 1];
        } else if (i < n && A[i] != B[j]) {
            if (j != 0) {
                j = lps[j - 1];
            } else {
                i++;
            }
        }
    }
    
    return result;
}

int main() {
    string A, B;
    getline(cin, A);
    getline(cin, B);
    
    vector<int> positions = kmpSearch(A, B);
    
    for (int i = 0; i < positions.size(); i++) {
        if (i > 0) cout << " ";
        cout << positions[i];
    }
    if (!positions.empty()) {
        cout << endl;
    }
    
    return 0;
}
```

## Tổng Kết

### Quy Trình Giải Quyết

1. **Nhận dạng bài toán:** Pattern Matching - bài toán classic
2. **Brute force:** Giải pháp đơn giản, phân tích worst case
3. **Nhận ra vấn đề:** Worst case $O(n \times m)$ quá chậm
4. **Tối ưu với KMP:** $O(n + m)$ đảm bảo mọi trường hợp
5. **Giải thích algorithm:** LPS array, cách hoạt động
6. **So sánh với các approach khác:** Rabin-Karp, Z-Algorithm

### Key Points

- **Time:** $O(n + m)$ với KMP
- **Space:** $O(m)$ cho LPS array
- **Khi nào dùng Brute Force:** Pattern ngắn, text ngắn, không có worst case
- **Khi nào dùng KMP:** Cần đảm bảo performance, pattern có overlapping
