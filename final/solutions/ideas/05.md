# Bài 5: Tìm Tất Cả Vị Trí Xuất Hiện Của Xâu B Trong Xâu A

## Đề Bài

Cho xâu A và xâu B chỉ gồm các chữ cái thường. Xâu B được gọi là xuất hiện tại vị trí $i$ của xâu A nếu:

$$A_i = B_1, A_{i+1} = B_2, \ldots, A_{i+\text{len}(B)-1} = B_{\text{len}(B)}$$

**Yêu cầu:** Hãy tìm tất cả các vị trí mà xâu B xuất hiện trong A.

**Dữ liệu vào:**
- Dòng 1: xâu A
- Dòng 2: xâu B
- Độ dài A, B không quá $10^6$

**Kết quả:**
- Ghi ra các vị trí tìm được trên 1 dòng (thứ tự tăng dần)
- Nếu B không xuất hiện trong A thì bỏ trắng

**Ví dụ:**
```
INPUT:
aaaaa
aa

OUTPUT:
1 2 3 4
```

**Link:** https://oj.vnoi.info/problem/substr#submit

---

## Phân Tích Bài Toán

### Hiểu Đề Bài

Đây là bài toán **Pattern Matching** (String Searching) classic.

**Ví dụ:** A = `"aaaaa"`, B = `"aa"`

Các vị trí B xuất hiện trong A:
- Vị trí 1: `"aa"` -> A[0..1] = "aa"
- Vị trí 2: `"aa"` -> A[1..2] = "aa"
- Vị trí 3: `"aa"` -> A[2..3] = "aa"
- Vị trí 4: `"aa"` -> A[3..4] = "aa"

Output: `1 2 3 4`

**Lưu ý:** Vị trí đếm từ 1 (1-indexed), không phải 0.

---

## Approach 1: Brute Force - Ý Tưởng Đơn Giản Nhất

### Ý Tưởng

**Nguyên tắc cơ bản:**

Kiểm tra từng vị trí một cách tuần tự, không bỏ sót bất kỳ khả năng nào.

**Các bước thực hiện chi tiết:**

1. **Xác định phạm vi tìm kiếm:**
   - Xâu A có độ dài $n$, xâu B có độ dài $m$
   - Vị trí bắt đầu hợp lệ: từ 0 đến $n - m$ (inclusive)
   - Tại sao? Nếu bắt đầu từ vị trí $> n-m$, không đủ $m$ ký tự để so sánh
   - Ví dụ: A = "hello" (n=5), B = "ll" (m=2) -> kiểm tra vị trí 0, 1, 2, 3

2. **So sánh tại mỗi vị trí:**
   - Với mỗi vị trí $i$, so sánh: $A[i+j]$ với $B[j]$ cho $j = 0, 1, \ldots, m-1$
   - **Nếu tất cả đều khớp:** Lưu vị trí $i+1$ (vì đếm từ 1)
   - **Nếu gặp bất kỳ ký tự không khớp:** Dừng ngay, chuyển sang vị trí tiếp theo

3. **Tối ưu nhỏ trong cài đặt:**
   - Sử dụng flag `match` để theo dõi trạng thái
   - Break sớm khi gặp mismatch để tiết kiệm thời gian
   - Chỉ thêm vào kết quả khi khớp hoàn toàn

**Hạn chế:**
- Worst case: Phải so sánh lại từ đầu nhiều lần
- Ví dụ xấu: A = "aaaaaaaaab", B = "aaab" -> mỗi vị trí phải so sánh gần hết mới biết không khớp

### Visualization

```
A = "a b c a b c a b c"
     0 1 2 3 4 5 6 7 8

B = "a b c"

Vị trí 0: [a b c] a b c a b c ✓ => Output: 1
Vị trí 1:  a [b c a] b c a b c ✗
Vị trí 2:  a b [c a b] c a b c ✗
Vị trí 3:  a b c [a b c] a b c ✓ => Output: 4
Vị trí 4:  a b c a [b c a] b c ✗
Vị trí 5:  a b c a b [c a b] c ✗
Vị trí 6:  a b c a b c [a b c] ✓ => Output: 7
```

### Code Implementation

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

// Brute Force: Kiểm tra từng vị trí có thể trong chuỗi A
// Time: O(n × m) - Được chấp nhận cho bài này
vector<int> bruteForce(const string& A, const string& B) {
    vector<int> result;
    int n = A.length();
    int m = B.length();
    
    // Pattern dài hơn chuỗi chính -> không thể tìm thấy
    if (m > n) return result;
    
    // Duyệt qua từng vị trí có thể bắt đầu trong A
    for (int i = 0; i <= n - m; i++) {
        bool match = true;
        
        // So sánh B với substring A[i..i+m-1] từng ký tự
        for (int j = 0; j < m; j++) {
            if (A[i + j] != B[j]) {  // Gặp ký tự không khớp
                match = false;       
                break;               
            }
        }
        
        // Nếu tất cả ký tự đều khớp -> Lưu vị trí
        if (match) {
            result.push_back(i + 1);  // +1 vì đề bài đếm từ 1 (1-indexed)
        }
    }
    
    return result;
}

int main() {
    string A, B;
    if (!getline(cin, A)) return 0;
    if (!getline(cin, B)) return 0;
    
    vector<int> positions = bruteForce(A, B);
    
    // In kết quả cách nhau bởi dấu cách
    for (int i = 0; i < positions.size(); i++) {
        cout << positions[i] << (i == positions.size() - 1 ? "" : " ");
    }
    if (!positions.empty()) {
        cout << endl;
    }

    return 0;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(n \times m)$

- Số vị trí cần kiểm tra: $n - m + 1 \approx O(n)$
- Mỗi vị trí: So sánh tối đa $m$ ký tự
- Worst case: Mỗi vị trí so sánh hết $m$ ký tự mới fail

**Space Complexity:** $O(1)$ (không tính output), nếu có thì $O(k)$ với $k$ là số lần xuất hiện của B trong A.




## Approach 2: KMP Algorithm - Tối Ưu

### Ý Tưởng

**Vấn đề của Brute Force:**

Khi gặp mismatch, Brute Force "quên" thông tin đã so sánh và bắt đầu lại từ đầu. Điều này lãng phí!

**Insight chính của KMP:**

**Knuth-Morris-Pratt (KMP)** tận dụng thông tin đã khớp để tránh so sánh lại không cần thiết.

**Quan sát quan trọng:**

Khi mismatch xảy ra sau khi khớp một phần pattern:
- **Brute force:** Lùi text pointer về 1 vị trí, reset pattern pointer về 0
- **KMP:** GIỮ text pointer, chỉ lùi pattern pointer dựa trên cấu trúc của pattern

**Ví dụ minh họa chi tiết:**

```
A = "abcabcabc"
B = "abcabd"

Tại vị trí 0:
  A: a b c a b c ...
  B: a b c a b d
     ✓ ✓ ✓ ✓ ✓ ✗  (mismatch tại d)

Brute force: Quay lại vị trí 1, so sánh lại từ đầu

KMP insight:
- Đã khớp "abcab" (5 ký tự)
- Phần đuôi "ab" của "abcab" trùng với phần đầu "ab" của pattern
- Không cần so sánh lại "ab", chỉ cần tiếp tục từ vị trí sau "ab"
```

**Thành phần chính của KMP:**

1. **LPS Array (Longest Proper Prefix-Suffix):**
   - Tiền xử lý pattern để tìm "cấu trúc lặp lại"
   - `lps[i]` = độ dài tiền tố dài nhất cũng là hậu tố của `pattern[0..i]`
   - **Ý nghĩa:** Cho biết khi mismatch, nên lùi pattern pointer về đâu

2. **Search phase:**
   - Duyệt text một lần duy nhất (text pointer chỉ tiến, không lùi)
   - Khi mismatch, dùng LPS để lùi pattern pointer thông minh
   - Khi pattern khớp hoàn toàn, lưu vị trí và tiếp tục tìm

**Tại sao KMP hiệu quả?**
- Text pointer không bao giờ lùi -> mỗi ký tự chỉ xem xét một lần
- Pattern pointer có thể lùi nhưng tổng số lần lùi ≤ $n$
- Độ phức tạp tuyến tính: $O(n + m)$ thay vì $O(n \times m)$

**Ví dụ minh họa:**

```
A = "abcabcabc"
B = "abcabd"

Brute force:
Vị trí 0: abcab[c] != abcab[d] (mismatch tại B[5])
          => Quay lại vị trí 1, bắt đầu lại
          
KMP insight:
- Đã khớp "abcab" (5 ký tự)
- Biết rằng "ab" ở cuối phần khớp cũng xuất hiện ở đầu pattern
- Có thể skip, không cần so sánh lại "ab"
```

### LPS Array (Longest Proper Prefix which is also Suffix)

**Định nghĩa:** `lps[i]` = độ dài của proper prefix dài nhất của `pattern[0..i]` mà cũng là suffix của `pattern[0..i]` (không tính chính nó).

**Proper prefix:** Prefix không bao gồm chính xâu đó.

**Ví dụ 1:** Pattern = `"aaaa"`

| i | pattern[0..i] | Proper Prefixes | Proper Suffixes | LPS |
|---|---------------|-----------------|-----------------|-----|
| 0 | "a"           | []              | []              | 0   |
| 1 | "aa"          | ["a"]           | ["a"]           | 1   |
| 2 | "aaa"         | ["a", "aa"]     | ["a", "aa"]     | 2   |
| 3 | "aaaa"        | ["a", "aa", "aaa"] | ["a", "aa", "aaa"] | 3   |

LPS = `[0, 1, 2, 3]`

**Ví dụ 2:** Pattern = `"abcabc"`

| i | pattern[0..i] | Longest Proper Prefix = Suffix | LPS |
|---|---------------|-------------------------------|-----|
| 0 | "a"           | -                             | 0   |
| 1 | "ab"          | -                             | 0   |
| 2 | "abc"         | -                             | 0   |
| 3 | "abca"        | "a"                           | 1   |
| 4 | "abcab"       | "ab"                          | 2   |
| 5 | "abcabc"      | "abc"                         | 3   |

LPS = `[0, 0, 0, 1, 2, 3]`

### Build LPS Array

**Trường hợp 1:** Khớp ký tự ``(if pattern[i] == pattern[len])``

- Ký tự hậu tố đang xét khớp với ký tự tiếp theo của tiền tố
- Ta mở rộng được độ dài chuỗi khớp thêm 1 đơn vị

**Trường hợp 2:** Không khớp
- Nếu trước đó đã khớp được đoạn dài `len != 0`:
    -  Ta không muốn bắt đầu lại từ đầu chuỗi mà sẽ tìm một tiền tố ngắn hơn nằm bên trong tiền tố vừa khớp, sao cho nó vẫn khớp với hậu tố hiện tại
    - Giá trị `lps[len-1]` cho ta biết: "Trong đoạn tiền tố vừa khớp (độ dài `len`), đoạn đầu và đoạn cuối trùng nhau dài bao nhiêu?". Ta nhảy len về vị trí đó để tiếp tục so sánh với `pattern[i]`.
- Nếu `len == 0`: Không có tiền tố nào khớp với hậu tố kết thúc tại i. Gán `lps[i] = 0` và đi tiếp sang ký tự sau.

```cpp
// Xây dựng mảng LPS (Longest Proper Prefix which is also Suffix)
// Time: O(m) - Mỗi ký tự chỉ xử lý một lần
vector<int> buildLPS(const string& pattern) {
    int m = pattern.length();
    vector<int> lps(m, 0);
    
    int len = 0;  // Độ dài của tiền tố dài nhất hiện tại
    int i = 1;    // Bắt đầu từ vị trí 1 (lps[0] luôn = 0)
    
    while (i < m) {
        if (pattern[i] == pattern[len]) {
            // Ký tự hiện tại khớp với ký tự ở cuối tiền tố
            len++;           // Mở rộng tiền tố
            lps[i] = len;    // Lưu độ dài tiền tố tại vị trí i
            i++;             // Tiếp tục với ký tự tiếp theo
        } else {
            // Không khớp
            if (len != 0) {
                // Thử với tiền tố ngắn hơn bằng cách lùi len
                len = lps[len - 1];
                // KHÔNG tăng i - thử lại với len mới
            } else {
                // Không có tiền tố nào khớp
                lps[i] = 0;
                i++;
            }
        }
    }
    
    return lps;
}
```

**Time:** $O(m)$ - Mỗi ký tự xử lý một lần

### KMP Search

Hàm duyệt mảng `A` một lần duy nhất, khi gặp ký tự không khớp, nó dùng mảng `lps` để biết cần lùi `j` về đâu an toàn nhất mà không cần so sánh lại từ đầu.

```cpp
// KMP Search: Tìm tất cả vị trí xuất hiện của B trong A
// Time: O(n + m)
vector<int> kmpSearch(const string& A, const string& B) {
    vector<int> result;
    int n = A.length();
    int m = B.length();
    
    // Trường hợp đặc biệt
    if (m > n || m == 0) return result;
    
    // Bước 1: Xây dựng mảng LPS cho pattern B
    vector<int> lps = buildLPS(B);  // O(m)
    
    int i = 0;  // Index duyệt chuỗi A
    int j = 0;  // Index duyệt pattern B
    
    // Bước 2: Duyệt chuỗi A một lần duy nhất
    while (i < n) {
        if (A[i] == B[j]) {
            // Ký tự khớp -> Tiếp tục cả hai con trỏ
            i++;
            j++;
        }
        
        // Kiểm tra xem đã khớp hết pattern chưa
        if (j == m) {
            // Tìm thấy. Vị trí bắt đầu là (i - j)
            result.push_back(i - j + 1);  // +1 vì đếm từ 1
            
            // Tiếp tục tìm các xuất hiện khác (overlapping)
            // Lùi j về vị trí an toàn nhờ LPS
            j = lps[j - 1];
        } 
        // Ký tự không khớp
        else if (i < n && A[i] != B[j]) {
            if (j != 0) {
                // Đã khớp một phần -> Lùi j theo LPS, KHÔNG lùi i
                j = lps[j - 1];
            } else {
                // Chưa khớp ký tự nào -> Tiếp tục sang ký tự tiếp theo trong A
                i++;
            }
        }
    }
    
    return result;
}
```

### Simulation

**Input:** A = `"aaaaa"`, B = `"aa"`

**Step 1:** Build LPS
- B = "aa"
- LPS = `[0, 1]`

**Step 2:** Search

| Step | i | j | A[i] | B[j] | Action | Found? | j after |
|------|---|---|------|------|--------|--------|---------|
| 1    | 0 | 0 | 'a' | 'a' | Match | - | 1 |
| 2    | 1 | 1 | 'a' | 'a' | Match, j==2 | Position 1 | lps[1]=1 |
| 3    | 2 | 1 | 'a' | 'a' | Match, j==2 | Position 2 | lps[1]=1 |
| 4    | 3 | 1 | 'a' | 'a' | Match, j==2 | Position 3 | lps[1]=1 |
| 5    | 4 | 1 | 'a' | 'a' | Match, j==2 | Position 4 | lps[1]=1 |
| 6    | 5 | - | - | - | i >= n, Done | - | - |

**Output:** `1 2 3 4`

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(n + m)$

- Build LPS: $O(m)$
- Search: $O(n)$
  - Pointer $i$ chỉ tăng, không lùi: $O(n)$
  - Pointer $j$ có thể lùi nhưng tổng số lần lùi $\leq n$: $O(n)$

**Space Complexity:** $O(m)$ cho LPS array

## Solution

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

// Xây dựng mảng LPS (Longest Proper Prefix which is also Suffix)
vector<int> buildLPS(const string& pattern) {
    int m = pattern.length();
    vector<int> lps(m, 0);
    
    int len = 0;  // Độ dài tiền tố hiện tại
    int i = 1;
    
    while (i < m) {
        if (pattern[i] == pattern[len]) {
            len++;
            lps[i] = len;
            i++;
        } else {
            if (len != 0) {
                len = lps[len - 1];  // Lùi về tiền tố ngắn hơn
            } else {
                lps[i] = 0;
                i++;
            }
        }
    }
    
    return lps;
}

// KMP Search - Thuật toán Knuth-Morris-Pratt
vector<int> kmpSearch(const string& A, const string& B) {
    vector<int> result;
    int n = A.length();
    int m = B.length();
    
    if (m > n || m == 0) return result;
    
    vector<int> lps = buildLPS(B);  // Xây dựng mảng LPS
    
    int i = 0;  // Index cho chuỗi A
    int j = 0;  // Index cho pattern B
    
    while (i < n) {
        if (A[i] == B[j]) {
            i++;
            j++;
        }
        
        if (j == m) {
            // Tìm thấy pattern
            result.push_back(i - j + 1);  // Vị trí 1-indexed
            j = lps[j - 1];               // Tiếp tục tìm overlapping matches
        } else if (i < n && A[i] != B[j]) {
            if (j != 0) {
                j = lps[j - 1];  // Sử dụng LPS để skip
            } else {
                i++;
            }
        }
    }
    
    return result;
}

int main() {
    ios_base::sync_with_stdio(false);  // Tối ưu I/O
    cin.tie(NULL);
    
    string A, B;
    getline(cin, A);
    getline(cin, B);
    
    vector<int> positions = kmpSearch(A, B);
    
    for (int i = 0; i < positions.size(); i++) {
        if (i > 0) cout << " ";
        cout << positions[i];
    }
    if (!positions.empty()) {
        cout << endl;
    }
    
    return 0;
}
```

## Tổng Kết

### Quy Trình Giải Quyết

1. **Nhận dạng bài toán:** Pattern Matching - bài toán classic
2. **Brute force:** Giải pháp đơn giản, phân tích worst case
3. **Nhận ra vấn đề:** Worst case $O(n \times m)$ quá chậm
4. **Tối ưu với KMP:** $O(n + m)$ đảm bảo mọi trường hợp
5. **Giải thích algorithm:** LPS array, cách hoạt động

### Key Points

- **Time:** $O(n + m)$ với KMP
- **Space:** $O(m)$ cho LPS array
- **Khi nào dùng Brute Force:** Pattern ngắn, text ngắn, không có worst case
- **Khi nào dùng KMP:** Cần đảm bảo performance, pattern có overlapping
