# Bài 1: Tìm Đoạn Con K Phần Tử Có GCD Lớn Nhất

## Đề Bài

Cho dãy số nguyên $a_1, a_2, \ldots, a_n$. Tìm một đoạn con có đúng $k$ phần tử liên tiếp sao cho ước chung lớn nhất của $k$ phần tử này là lớn nhất.

**Dữ liệu vào:**
- Dòng đầu: $n, k$ ($2 \leq k \leq n \leq 10^3$)
- Dòng tiếp theo: $a_1, a_2, \ldots, a_n$ ($1 \leq a_i \leq 10^6$)

**Kết quả:**
- Giá trị lớn nhất của ước chung lớn nhất của $k$ phần tử liên tiếp

**Ví dụ:**
```
INPUT:
10 3
2 6 4 3 18 12 24 8 7 5

OUTPUT:
6
```

---

## Phân Tích Bài Toán

### Hiểu Đề Bài

Cho dãy: `[2, 6, 4, 3, 18, 12, 24, 8, 7, 5]`, $k = 3$

Các đoạn con 3 phần tử liên tiếp:
- `[2, 6, 4]` → $\gcd(2, 6, 4) = 2$
- `[6, 4, 3]` → $\gcd(6, 4, 3) = 1$
- `[4, 3, 18]` → $\gcd(4, 3, 18) = 1$
- `[3, 18, 12]` → $\gcd(3, 18, 12) = 3$
- `[18, 12, 24]` → $\gcd(18, 12, 24) = 6$ **(MAX)**
- `[12, 24, 8]` → $\gcd(12, 24, 8) = 4$
- `[24, 8, 7]` → $\gcd(24, 8, 7) = 1$
- `[8, 7, 5]` → $\gcd(8, 7, 5) = 1$

Đáp án: **6**

---

## Approach 1: Brute Force kết hợp Sliding Window

### Ý Tưởng

1. **Liệt kê tất cả các đoạn con:** Có $n - k + 1$ đoạn con $k$ phần tử liên tiếp
2. **Tính GCD cho mỗi đoạn:** Sử dụng thuật toán Euclid: $GCD(a, b, c) = GCD(a, GCD(b, c))$.
3. **Lưu GCD lớn nhất:** So sánh và cập nhật kết quả


### Code Implementation

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// Thuật toán Euclid để tính GCD
// Time: O(log(min(a, b)))
int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

// Tính GCD của k phần tử liên tiếp từ vị trí start
// Time: O(k * log(max_a))
int gcdOfSegment(int arr[], int start, int k) {
    int result = arr[start];
    for (int i = start + 1; i < start + k; i++) {
        result = gcd(result, arr[i]);
    }
    return result;
}

// Solution 1: Brute Force
int solution1_bruteforce(int arr[], int n, int k) {
    int maxGCD = 0;
    
    // Duyệt qua tất cả các đoạn con k phần tử
    for (int i = 0; i <= n - k; i++) {
        int currentGCD = gcdOfSegment(arr, i, k);
        maxGCD = max(maxGCD, currentGCD);
    }
    
    return maxGCD;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(n \times k \times \log(\max(a_i)))$

- Số đoạn con: $n - k + 1 \approx O(n)$
- Tính GCD của $k$ số: $O(k \times \log(\max(a_i)))$
  - Mỗi phép GCD: $O(\log(\max(a_i)))$
  - Cần $k - 1$ phép GCD

**Space Complexity:** $O(1)$

### Đánh Giá

Với ràng buộc $n \leq 1000$, $k \leq 1000$, $a_i \leq 10^6$:
- $O(1000 \times 1000 \times 20) \approx 20,000,000$ operations
- **Kết luận:** Hoàn toàn chấp nhận được!

## Approach 2: Optimized với Early Stopping

### Quan Sát Quan Trọng

1. **Nếu GCD = 1:** Không thể nhỏ hơn nữa, có thể skip sớm trong quá trình tính
2. **GCD không thể vượt quá:** Giá trị lớn nhất trong dãy
3. **Early stopping:** Nếu đã tìm được GCD = $\max(a_i)$, không cần tìm nữa

### Cải Tiến

```cpp
int solution2_optimized(int arr[], int n, int k) {
    int maxGCD = 0;
    
    // Tìm giá trị lớn nhất trong dãy
    int maxValue = 0;
    for (int i = 0; i < n; i++) {
        maxValue = max(maxValue, arr[i]);
    }
    
    // Duyệt qua tất cả các đoạn con
    for (int i = 0; i <= n - k; i++) {
        // Tính GCD với early break khi = 1
        int currentGCD = arr[i];
        for (int j = i + 1; j < i + k; j++) {
            currentGCD = gcd(currentGCD, arr[j]);
            if (currentGCD == 1) break; // Early stopping
        }
        
        maxGCD = max(maxGCD, currentGCD);
        
        // Nếu đã đạt max có thể, return ngay
        if (maxGCD == maxValue) {
            return maxGCD;
        }
    }
    
    return maxGCD;
}
```

### Phân Tích

**Time Complexity:** 
- Worst case: vẫn $O(n \times k \times \log(\max(a_i)))$
- Average case: Tốt hơn đáng kể nhờ early stopping

**Space Complexity:** $O(1)$

## Solution

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

int main() {
    int n, k;
    cin >> n >> k;
    
    int arr[1000];
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }
    
    int maxGCD = 0;
    int maxValue = 0;
    
    // Tìm max value
    for (int i = 0; i < n; i++) {
        maxValue = max(maxValue, arr[i]);
    }
    
    // Duyệt qua tất cả đoạn con k phần tử
    for (int i = 0; i <= n - k; i++) {
        int currentGCD = arr[i];
        
        // Tính GCD của đoạn hiện tại
        for (int j = i + 1; j < i + k; j++) {
            currentGCD = gcd(currentGCD, arr[j]);
            if (currentGCD == 1) break; // Không thể nhỏ hơn
        }
        
        maxGCD = max(maxGCD, currentGCD);
        
        // Early stopping
        if (maxGCD == maxValue) {
            break;
        }
    }
    
    cout << maxGCD << endl;
    
    return 0;
}
```

### Độ phức tạp

**Time Complexity: $O(n \times k \times \log(\max(a_i)))$** 

**Space Complexity:** $O(n)$

## Mở rộng: Dùng Sparse Table khi N rất lớn

### **Tóm tắt ý tưởng thuật toán:**

* Dùng **Sparse Table** để tiền xử lý mảng, lưu GCD của mọi đoạn có độ dài (2^j).
* Nhờ tính chất kết hợp của GCD, mỗi truy vấn GCD trên đoạn bất kỳ ([L, R]) được trả lời trong **O(1)** bằng cách ghép hai đoạn chồng nhau.
* Sau khi xây bảng trong **O(n log n)**, duyệt tất cả các **cửa sổ độ dài k**, truy vấn GCD cho từng cửa sổ và lấy **giá trị lớn nhất** trong số đó.

### **Cài đặt:**

``` cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>

using namespace std;

const int MAXN = 100005; // Giả sử N tối đa 10^5
const int LOG = 17;      // 2^17 > 10^5
int st[MAXN][LOG];       // Bảng Sparse Table
int bin_log[MAXN];       // Mảng lưu log2 để tra cứu nhanh

int gcd(int a, int b) {
    while (b) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

void build(const vector<int>& a, int n) {
    // Tính trước log2 cho mọi số từ 1 đến N
    bin_log[1] = 0;
    for (int i = 2; i <= n; i++)
        bin_log[i] = bin_log[i/2] + 1;

    // Khởi tạo cột đầu tiên (độ dài 2^0 = 1)
    for (int i = 0; i < n; i++)
        st[i][0] = a[i];

    // Quy hoạch động xây bảng
    for (int j = 1; j < LOG; j++) {
        for (int i = 0; i + (1 << j) <= n; i++) {
            st[i][j] = gcd(st[i][j-1], st[i + (1 << (j-1))][j-1]);
        }
    }
}

int query(int L, int R) {
    int j = bin_log[R - L + 1];
    // GCD đoạn [L, R] = GCD(đoạn đầu dài 2^j, đoạn cuối dài 2^j)
    return gcd(st[L][j], st[R - (1 << j) + 1][j]);
}

int main() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    build(a, n);

    int max_gcd = 0;
    // Duyệt qua tất cả cửa sổ độ dài k
    for (int i = 0; i <= n - k; i++) {
        // Truy vấn đoạn từ i đến i+k-1
        max_gcd = max(max_gcd, query(i, i + k - 1));
    }

    cout << max_gcd << endl;
    return 0;
}
```

### Phân Tích

**Time Complexity: $O(n \log n)$** 
- Tiền xử lý: $O(n \log n)$
- Truy vấn: $O(1)$

**Space Complexity:** $O(n \log n)$

## Mở rộng: Dùng Segment Tree khi N rất lớn

### **Tóm tắt ý tưởng thuật toán:**

* Xây dựng **Segment Tree** lưu **GCD của từng đoạn con** của mảng.
* Mỗi nút quản lý một khoảng và giá trị nút là **GCD của hai nút con**, nên truy vấn GCD trên bất kỳ đoạn nào đều thực hiện được.
* Sau khi xây cây trong **O(n)**, duyệt tất cả các **cửa sổ trượt độ dài k**, mỗi lần truy vấn GCD trong **O(log n)** và lấy **giá trị lớn nhất** trong các cửa sổ.


### **Cài đặt:**

``` cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// Khai báo mảng cây và mảng dữ liệu
// 4 * N là kích thước an toàn cho Segment Tree
const int MAXN = 100005; 
int tree[4 * MAXN];
int a[MAXN];

// Hàm tìm GCD
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

// 1. Hàm xây dựng cây (Build)
// node: chỉ số hiện tại trong mảng tree
// start, end: phạm vi mảng a mà node này quản lý
void build(int node, int start, int end) {
    if (start == end) {
        // Nút lá
        tree[node] = a[start];
    } else {
        int mid = (start + end) / 2;
        // Xây dựng con trái (2*node) và con phải (2*node + 1)
        build(2 * node, start, mid);
        build(2 * node + 1, mid + 1, end);
        
        // Giá trị nút cha = GCD của 2 nút con
        tree[node] = gcd(tree[2 * node], tree[2 * node + 1]);
    }
}

// 2. Hàm truy vấn (Query)
// l, r: phạm vi cần tìm GCD (đoạn con độ dài K)
int query(int node, int start, int end, int l, int r) {
    // Trường hợp 1: Phạm vi nút nằm hoàn toàn ngoài đoạn [l, r]
    if (r < start || end < l) {
        return 0; // Trả về 0 để không ảnh hưởng kết quả GCD
    }
    
    // Trường hợp 2: Phạm vi nút nằm hoàn toàn trong đoạn [l, r]
    if (l <= start && end <= r) {
        return tree[node];
    }
    
    // Trường hợp 3: Giao nhau một phần -> Đệ quy xuống con
    int mid = (start + end) / 2;
    int p1 = query(2 * node, start, mid, l, r);
    int p2 = query(2 * node + 1, mid + 1, end, l, r);
    
    return gcd(p1, p2);
}

int main() {
    // Tối ưu nhập xuất
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, k;
    if (cin >> n >> k) {
        for (int i = 0; i < n; i++) {
            cin >> a[i];
        }

        // Xây dựng Segment Tree
        // Nút gốc là 1, quản lý từ 0 đến n-1
        build(1, 0, n - 1);

        int max_gcd = 0;
        
        // Duyệt qua các cửa sổ trượt độ dài K
        // Cửa sổ từ i đến i + k - 1
        for (int i = 0; i <= n - k; i++) {
            int current_gcd = query(1, 0, n - 1, i, i + k - 1);
            if (current_gcd > max_gcd) {
                max_gcd = current_gcd;
            }
        }

        cout << max_gcd << endl;
    }
    return 0;
}
```

### Phân Tích

**Time Complexity: $O(n \log n)$** 
- Tiền xử lý: $O(n)$
- Truy vấn trong vòng lặp: $O(\log n)$, lặp khoảng $n$ lần (cửa sổ trượt).

**Space Complexity:** $O(n)$

$\Rightarrow$ An toàn hơn về bộ nhớ, phù hợp với N lớn hơn $10^6$, hỗ trợ nếu có cập nhật giá trị.

- **Khi nào dừng tối ưu:** Khi solution đã đủ tốt với constraints

### Câu Hỏi Mở Rộng Có Thể Gặp

**Q: Nếu $n = 10^6$ thì sao?**
- A: Cần Segment Tree hoặc Sparse Table cho GCD query: $O(n \log n)$ + $O(\log n)$ per query

**Q: Nếu cần tìm vị trí đoạn con, không chỉ GCD?**
- A: Lưu thêm biến `bestIndex`, return `(maxGCD, bestIndex)`

**Q: Có thể precompute gì không?**
- A: Có thể precompute GCD prefixes, nhưng vẫn cần $O(k)$ để tính GCD đoạn con
