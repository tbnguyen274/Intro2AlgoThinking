# Bài 1: Tìm Đoạn Con K Phần Tử Có GCD Lớn Nhất

## Đề Bài

Cho dãy số nguyên $a_1, a_2, \ldots, a_n$. Tìm một đoạn con có đúng $k$ phần tử liên tiếp sao cho ước chung lớn nhất của $k$ phần tử này là lớn nhất.

**Dữ liệu vào:**
- Dòng đầu: $n, k$ ($2 \leq k \leq n \leq 10^3$)
- Dòng tiếp theo: $a_1, a_2, \ldots, a_n$ ($1 \leq a_i \leq 10^6$)

**Kết quả:**
- Giá trị lớn nhất của ước chung lớn nhất của $k$ phần tử liên tiếp

**Ví dụ:**
```
INPUT:
10 3
2 6 4 3 18 12 24 8 7 5

OUTPUT:
6
```

---

## Phân Tích Bài Toán

### Hiểu Đề Bài

Cho dãy: `[2, 6, 4, 3, 18, 12, 24, 8, 7, 5]`, $k = 3$

Các đoạn con 3 phần tử liên tiếp:
- `[2, 6, 4]` → $\gcd(2, 6, 4) = 2$
- `[6, 4, 3]` → $\gcd(6, 4, 3) = 1$
- `[4, 3, 18]` → $\gcd(4, 3, 18) = 1$
- `[3, 18, 12]` → $\gcd(3, 18, 12) = 3$
- `[18, 12, 24]` → $\gcd(18, 12, 24) = 6$ **(MAX)**
- `[12, 24, 8]` → $\gcd(12, 24, 8) = 4$
- `[24, 8, 7]` → $\gcd(24, 8, 7) = 1$
- `[8, 7, 5]` → $\gcd(8, 7, 5) = 1$

Đáp án: **6**

---

## Approach 1: Brute Force kết hợp Sliding Window

### Ý Tưởng

**Tư duy tiếp cận:**

Bài toán yêu cầu tìm GCD lớn nhất trong tất cả các đoạn con có đúng $k$ phần tử liên tiếp. Cách tiếp cận đơn giản nhất là thử tất cả các khả năng.

**Các bước thực hiện:**

1. **Liệt kê tất cả đoạn con $k$ phần tử:**
   - Với mảng có $n$ phần tử, các đoạn con bắt đầu từ vị trí $i = 0, 1, 2, \ldots, n-k$
   - Tổng cộng có $n - k + 1$ đoạn con cần kiểm tra
   - Ví dụ: Mảng 10 phần tử, $k=3$ → có 8 đoạn con (từ vị trí 0→7)

2. **Tính GCD cho từng đoạn con:**
   - Sử dụng **thuật toán Euclid** để tính GCD của 2 số: $O(\log(\min(a,b)))$
   - Áp dụng tính chất kết hợp: $\text{GCD}(a, b, c) = \text{GCD}(\text{GCD}(a, b), c)$
   - Với $k$ phần tử, cần $k-1$ lần tính GCD
   - Ví dụ: GCD(12, 18, 24) = GCD(GCD(12, 18), 24) = GCD(6, 24) = 6

3. **Theo dõi và cập nhật kết quả:**
   - Khởi tạo biến `maxGCD = 0`
   - Sau mỗi lần tính GCD của một đoạn con, so sánh với `maxGCD`
   - Cập nhật nếu tìm được GCD lớn hơn

**Tại sao approach này hiệu quả?**
- Đơn giản, dễ hiểu, dễ implement
- Đảm bảo không bỏ sót bất kỳ đoạn con nào
- Với ràng buộc $n \leq 1000$, độ phức tạp $O(n \times k)$ hoàn toàn chấp nhận được


### Code Implementation

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// Thuật toán Euclid để tính GCD (Greatest Common Divisor - Ước chung lớn nhất)
// Time: O(log(min(a, b))) - cực kỳ nhanh
int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;  // Lấy phần dư
        a = temp;   // Hoán đổi
    }
    return a;  // Khi b = 0, a là GCD
}

// Tính GCD của k phần tử liên tiếp bắt đầu từ vị trí start
// Time: O(k × log(max_a))
int gcdOfSegment(const vector<int>& arr, int start, int k) {
    int result = arr[start];  // Khởi tạo bằng phần tử đầu tiên
    // Tính GCD dồn từ trái sang phải: gcd(gcd(a,b), c) = gcd(a, b, c)
    for (int i = start + 1; i < start + k; i++) {
        result = gcd(result, arr[i]);
    }
    return result;
}

// Solution 1: Brute Force - Duyệt tất cả các đoạn con k phần tử
// Time: O(n × k × log(max_a))
int solution1_bruteforce(const vector<int>& arr, int k) {
    int maxGCD = 0;  // GCD lớn nhất tìm được
    int n = (int)arr.size();
    
    // Duyệt qua tất cả các đoạn con gồm k phần tử liên tiếp
    // Có (n - k + 1) đoạn con như vậy
    for (int i = 0; i <= n - k; i++) {
        int currentGCD = gcdOfSegment(arr, i, k);  // Tính GCD của đoạn [i, i+k)
        maxGCD = max(maxGCD, currentGCD);        // Cập nhật max
    }
    return maxGCD;
}

int main() {
    int n, k;
    cin >> n >> k;  // Nhập số phần tử và độ dài đoạn con
    
    vector<int> arr(n);
    for (int i = 0; i < n; i++) {
        cin >> arr[i];  // Nhập dãy số
    }
    
    int result = solution1_bruteforce(arr, k);
    cout << result << endl;  // In ra GCD lớn nhất
    
    return 0;
}
```

### Phân Tích Độ Phức Tạp

**Time Complexity:** $O(n \times k \times \log(\max(a_i)))$

- Số đoạn con: $n - k + 1 \approx O(n)$
- Tính GCD của $k$ số: $O(k \times \log(\max(a_i)))$
  - Mỗi phép GCD: $O(\log(\max(a_i)))$
  - Cần $k - 1$ phép GCD

**Space Complexity:** $O(1)$

### Đánh Giá

Với ràng buộc $n \leq 1000$, $k \leq 1000$, $a_i \leq 10^6$:
- $O(1000 \times 1000 \times 20) \approx 20,000,000$ operations
- **Kết luận:** Hoàn toàn chấp nhận được!

## Approach 2: Optimized với Early Stopping

### Ý Tưởng

**Tối ưu hóa dựa trên quan sát:**

Approach 1 đã hoạt động tốt, nhưng chúng ta có thể tối ưu hơn bằng cách tận dụng các tính chất của GCD.

**Quan sát quan trọng:**

1. **GCD có giới hạn trên:**
   - GCD của một tập số không bao giờ lớn hơn số nhỏ nhất trong tập đó
   - Do đó: $\text{GCD}(a_1, a_2, \ldots, a_k) \leq \min(a_1, a_2, \ldots, a_k) \leq \max(\text{toàn bộ mảng})$
   - **Ý nghĩa:** Nếu đã tìm được GCD = $\max(a_i)$, đó chính là đáp án tối ưu!

2. **GCD có giới hạn dưới là 1:**
   - Khi tính GCD tuần tự, nếu kết quả = 1, tiếp tục tính cũng không thay đổi
   - **Tối ưu:** Gặp GCD = 1, dừng ngay, không cần tính nữa
   - Ví dụ: GCD(12, 18, 7) → GCD(12, 18) = 6 → GCD(6, 7) = 1 → STOP

3. **Tính chất đơn điệu của GCD:**
   - Khi thêm số vào tập, GCD chỉ có thể giữ nguyên hoặc giảm, không bao giờ tăng
   - $\text{GCD}(a, b, c) \leq \text{GCD}(a, b)$

**Cải tiến so với Approach 1:**

- **Precompute:** Tính `maxValue` một lần duy nhất trước khi duyệt
- **Early break trong vòng lặp con:** Nếu GCD = 1 → break ngay
- **Early return toàn bộ:** Nếu `maxGCD == maxValue` → return luôn

**Hiệu quả thực tế:**
- Worst case: Vẫn $O(n \times k)$ (giống Approach 1)
- Average case: **Nhanh hơn đáng kể** nhờ early stopping
- Đặc biệt tốt khi:
  - Có nhiều số nguyên tố cùng nhau (GCD = 1 sớm)
  - Tồn tại đoạn con có GCD = max value

### Cải Tiến

```cpp
#include <iostream>
#include <algorithm>

using namespace std;

// Solution 2: Optimized with Early Stopping
// Tối ưu hóa bằng cách dừng sớm khi gặp GCD = 1 hoặc GCD = max_value
int solution2_optimized(const vector<int>& arr, int k) {
    int maxGCD = 0;  // Kết quả cuối cùng
    int n = (int)arr.size();
    
    // Tìm giá trị lớn nhất trong dãy (trạn trên của GCD)
    // Vì GCD không bao giờ vượt quá số nhỏ nhất trong tập
    int maxValue = 0;
    for (int i = 0; i < n; i++) {
        maxValue = max(maxValue, arr[i]);
    }

    // Duyệt qua tất cả các đoạn con k phần tử
    for (int i = 0; i <= n - k; i++) {
        // Tính GCD của đoạn con [i, i+k)
        int currentGCD = arr[i];  // Bắt đầu với phần tử đầu tiên
        
        for (int j = i + 1; j < i + k; j++) {
            currentGCD = gcd(currentGCD, arr[j]);
            
            // Early stopping 1: Nếu GCD = 1, không thể giảm thêm
            // (Mọi số đều chia hết cho 1, không có ước chung > 1)
            if (currentGCD == 1) break;
        }

        maxGCD = max(maxGCD, currentGCD);  // Cập nhật kết quả tốt nhất

        // Early stopping 2: Nếu GCD đạt giá trị max có thể, return ngay
        // Ví dụ: [12, 6, 3] → GCD = 3, không thể cao hơn arr[i] bất kỳ
        if (maxGCD == maxValue) {
            return maxGCD;  // Đã tối ưu, không cần tính tiếp
        }
    }

    return maxGCD;
}

int main() {
    int n, k;
    cin >> n >> k;
    
    vector<int> arr(n);
    for (int i = 0; i < n; i++) {
        cin >> arr[i];
    }
    
    int result = solution2_optimized(arr, k);
    cout << result << endl;
    
    return 0;
}
```

### Phân Tích

**Time Complexity:** 
- Worst case: vẫn $O(n \times k \times \log(\max(a_i)))$
- Average case: Tốt hơn đáng kể nhờ early stopping

**Space Complexity:** $O(1)$

## Mở rộng: Dùng Sparse Table khi N rất lớn

### **Tóm tắt ý tưởng thuật toán:**

* Dùng **Sparse Table** để tiền xử lý mảng, lưu GCD của mọi đoạn có độ dài ($2^j$).
* Nhờ tính chất kết hợp của GCD, mỗi truy vấn GCD trên đoạn bất kỳ ([L, R]) được trả lời trong **O(1)** bằng cách ghép hai đoạn chồng nhau.
* Sau khi xây bảng trong **O(n log n)**, duyệt tất cả các **cửa sổ độ dài k**, truy vấn GCD cho từng cửa sổ và lấy **giá trị lớn nhất** trong số đó.

### **Cài đặt:**

``` cpp
#include <iostream>
#include <vector>
#include <cmath>
#include <algorithm>

using namespace std;

int gcd(int a, int b) {
    while (b) {
        int t = a % b;
        a = b;
        b = t;
    }
    return a;
}

// Build sparse table using vectors
void build(const vector<int>& a, vector<vector<int>>& st, vector<int>& bin_log, int n, int LOG) {
    bin_log[1] = 0;
    for (int i = 2; i <= n; i++)
        bin_log[i] = bin_log[i/2] + 1;

    for (int i = 0; i < n; i++) st[i][0] = a[i];

    for (int j = 1; j < LOG; j++) {
        for (int i = 0; i + (1 << j) <= n; i++) {
            st[i][j] = gcd(st[i][j-1], st[i + (1 << (j-1))][j-1]);
        }
    }
}

int query(const vector<vector<int>>& st, const vector<int>& bin_log, int L, int R) {
    int j = bin_log[R - L + 1];
    return gcd(st[L][j], st[R - (1 << j) + 1][j]);
}

int main() {
    int n, k;
    cin >> n >> k;
    vector<int> a(n);
    for (int i = 0; i < n; i++) cin >> a[i];

    int LOG = 0; while ((1 << LOG) <= n) ++LOG;
    vector<vector<int>> st(n, vector<int>(LOG));
    vector<int> bin_log(n + 1);

    build(a, st, bin_log, n, LOG);

    int max_gcd = 0;
    for (int i = 0; i <= n - k; i++) {
        max_gcd = max(max_gcd, query(st, bin_log, i, i + k - 1));
    }

    cout << max_gcd << endl;
    return 0;
}
```

### Phân Tích

**Time Complexity: $O(n \log n)$** 
- Tiền xử lý: $O(n \log n)$
- Truy vấn: $O(1)$

**Space Complexity:** $O(n \log n)$

## Mở rộng: Dùng Segment Tree khi N rất lớn

### **Tóm tắt ý tưởng thuật toán:**

* Xây dựng **Segment Tree** lưu **GCD của từng đoạn con** của mảng.
* Mỗi nút quản lý một khoảng và giá trị nút là **GCD của hai nút con**, nên truy vấn GCD trên bất kỳ đoạn nào đều thực hiện được.
* Sau khi xây cây trong **O(n)**, duyệt tất cả các **cửa sổ trượt độ dài k**, mỗi lần truy vấn GCD trong **O(log n)** và lấy **giá trị lớn nhất** trong các cửa sổ.


### **Cài đặt:**

``` cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

// Sử dụng vector cho cây và dữ liệu
vector<int> segtree;
vector<int> arr;

// Hàm tìm GCD
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}

void build(int node, int start, int end) {
    if (start == end) {
        segtree[node] = arr[start];
    } else {
        int mid = (start + end) / 2;
        build(2 * node, start, mid);
        build(2 * node + 1, mid + 1, end);
        segtree[node] = gcd(segtree[2 * node], segtree[2 * node + 1]);
    }
}

int query(int node, int start, int end, int l, int r) {
    if (r < start || end < l) return 0;
    if (l <= start && end <= r) return segtree[node];
    int mid = (start + end) / 2;
    int p1 = query(2 * node, start, mid, l, r);
    int p2 = query(2 * node + 1, mid + 1, end, l, r);
    return gcd(p1, p2);
}

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(NULL);

    int n, k;
    if (cin >> n >> k) {
        arr.assign(n, 0);
        for (int i = 0; i < n; i++) cin >> arr[i];

        segtree.assign(4 * n, 0);
        build(1, 0, n - 1);

        int max_gcd = 0;
        for (int i = 0; i <= n - k; i++) {
            int current_gcd = query(1, 0, n - 1, i, i + k - 1);
            if (current_gcd > max_gcd) max_gcd = current_gcd;
        }

        cout << max_gcd << endl;
    }
    return 0;
}
```

### Phân Tích

**Time Complexity: $O(n \log n)$** 
- Tiền xử lý: $O(n)$
- Truy vấn trong vòng lặp: $O(\log n)$, lặp khoảng $n$ lần (cửa sổ trượt).

**Space Complexity:** $O(n)$

$\Rightarrow$ An toàn hơn về bộ nhớ, phù hợp với N lớn hơn $10^6$, hỗ trợ nếu có cập nhật giá trị.

### Câu Hỏi Mở Rộng Có Thể Gặp

**Q: Nếu $n = 10^6$ thì sao?**
- A: Cần Segment Tree hoặc Sparse Table cho GCD query: $O(n \log n)$ + $O(\log n)$ per query

**Q: Nếu cần tìm vị trí đoạn con, không chỉ GCD?**
- A: Lưu thêm biến `bestIndex`, return `(maxGCD, bestIndex)`

**Q: Có thể precompute gì không?**
- A: Có thể precompute GCD prefixes, nhưng vẫn cần $O(k)$ để tính GCD đoạn con
